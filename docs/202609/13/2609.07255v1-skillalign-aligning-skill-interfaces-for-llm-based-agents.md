## 摘要
语言模型智能体越来越依赖技能：用于推理、工具使用和交互的可复用程序性知识。现有工作研究技能如何被获取、检索、压缩或组合，但通常假设一旦选定技能，其与智能体的接口就是固定的。我们认为这忽略了一个技能效用的关键来源：同一技能可能因其暴露方式不同而产生帮助、干扰或误导。我们提出 SkillAlign，一个与提供方无关的框架，将候选技能表示为多视图程序卡片，并通过不同的暴露接口进行呈现，包括完整指令、提示、压缩摘要、工作流或不暴露。这使得可以在任务、智能体和候选技能保持不变、仅暴露接口变化的情况下进行反事实评估。在 ALFWorld 和 SkillsBench 上，我们表明暴露形式会显著影响任务成功率和渲染上下文成本，并且紧凑的 top-k 暴露可以优于全库注入。我们进一步在 ALFWorld 上进行了基于回放的政策学习分析，表明自适应暴露包含可学习信号，但仍远未达到预言机选择水平。我们的结果表明，技能增强型智能体不仅应优化使用哪些技能，还应优化这些技能的呈现方式。

## Abstract
Language-model agents increasingly rely on skills: reusable procedural knowledge for reasoning, tool use, and interaction. Existing work studies how skills are acquired, retrieved, compressed, or composed, but often assumes that once a skill is selected, its interface to the agent is fixed. We argue that this overlooks a key source of skill utility: the same skill can help, distract, or mislead depending on how it is exposed. We propose SkillAlign, a provider-agnostic framework that represents candidate skills as multi-view procedural cards and renders them through alternative exposure interfaces, including full instructions, hints, compressed summaries, workflows, or no exposure. This enables counterfactual evaluation where the task, agent, and candidate skills are fixed while only the exposure interface varies. Across ALFWorld and SkillsBench, we show that exposure form substantially affects task success and rendered context cost, and that compact top-k exposure can outperform full-library injection. We further conduct a replay-based policy-learning analysis on ALFWorld, showing that adaptive exposure contains learnable signal but remains far from oracle selection. Our results suggest that skill-augmented agents should optimize not only which skills to use, but also how those skills are presented.

## 6. 论文的主要结论与发现

- **暴露形式是一等变量**：在相同候选技能下，仅改变暴露接口即可导致成功率/奖励显著变化。例如 ALFWorld 中 All 来源下成功率可从 47.9 到 72.1 波动（MiniMax）。
- **候选质量与暴露形式交互**：top-k 检索先减少无关技能，SkillAlign 再控制表现方式，两者互补。
- **紧凑暴露通常更高效**：`hint` 和 `compressed` 在低得多的上下文成本下常达到甚至超过 `full` 的表现；`compressed` 在技术任务上优于 `hint`，因为保留了更多操作细节。
- **`All + Full` 作为诊断条件**：全库完整注入因后端截断、注意力稀释、无关先验、指令冲突等因素表现较差，不宜作为实用策略。
- **效应在不同提供方下持续存在**：图提供方下，`compressed` 依然普遍最佳，`full` 成本高且非一致更好。
- **技能库增大使暴露问题更突出**：全量暴露在技能库增长时急剧下降，紧凑接口相对稳定。
- **自适应暴露有可学习信号**：SFT/DPO 政策在回放评估中优于最佳固定接口，DPO 略有增益；但与 Oracle 暴露差距很大，说明还有巨大上升空间。

## 7. 优点

- **问题定义新颖**：明确区分“技能选择”与“技能暴露”，填补了技能增强智能体研究中的缺口。
- **方法简洁而通用**：SkillAlign 与提供方无关，不依赖特定检索系统，可作为现有技能生态的附加层。
- **反事实评估协议严格**：固定任务、后端、候选技能，仅改变接口，能清晰归因接口效应。
- **多维度实验设计**：覆盖多个基准、后端、提供方、技能库规模和消融分析，证据较充分。
- **成本-性能权衡视角**：不仅报告性能，还报告渲染上下文成本，强调效率与效用的平衡。
- **人工保真审计**：对生成视图的遗漏、扭曲、矛盾进行人工检查，增强了结果可信度。
- **政策学习探索**：虽为轻量，但展示了自适应暴露的可行性，并为未来研究指出方向。

## 8. 不足与局限

- **接口集合有限**：目前只有五种手工设计接口，未覆盖全部可能的技能表征空间，未来可学习更丰富的接口或生成任务自适应视图。
- **政策学习较简单**：SFT/DPO 仅用于可行性验证，离 Oracle 差距大；未使用在线强化学习，也未对政策模型做充分调优。
- **依赖候选技能质量**：SkillAlign 不替代检索，糟糕的候选集仍会限制收益；需与检索系统联合优化。
- **实验覆盖有限**：主要基于 ALFWorld 和 SkillsBench，未在更多样化环境中验证；政策学习仅在 ALFWorld 上回放评估，未进行真实在线交互。
- **未完全解耦长度与结构**：虽然做了长度匹配摘要消融，但长度与结构的交互可能仍存在混杂；`All + Full` 的退化机制未完全分离。
- **部分结果差异较小**：任务级 bootstrap 置信区间常有重叠，某些数值优势可能不具有统计显著性。
- **生成视图的保真风险**：人工审计显示罕见但不是零的遗漏、扭曲或误导性添加，安全敏感场景需额外验证和回退机制。
