## 摘要
推理智能体越来越依赖网络搜索等外部工具来回答复杂查询。强化学习（RL）微调算法（如 GRPO）已改善了纯文本语言模型中的长程推理，尤其是在编程和数学方面。然而，多模态智能体中可靠的工具使用仍具挑战性，因为模型必须在整合含噪检索证据的同时理解文本和图像，而且往往处于稀疏的结果级监督下，缺乏明确的验证信号。我们提出了通过强化学习实现自我验证（Self-Verification via Reinforcement Learning，SVRL），这是一个仅使用强化学习的微调框架，训练多模态智能体在其自身的推理轨迹中验证和筛选检索到的证据，从而在推理时减少对外部验证器的依赖。SVRL 还引入了搜索感知惩罚，以减少不必要的工具调用；以及查询多样性奖励，以鼓励多样且形式良好的搜索查询，从而就何时搜索以及搜索什么提供细粒度反馈。仅用 5,000 个视觉问答样本对 Qwen-2.5-VL-7B 进行 SVRL 微调，即可在多个基准上一致提升多跳视觉问答的泛化能力和工具使用效率。总体而言，SVRL 缩小了紧凑型智能体与规模大得多的专有模型之间的差距，同时所需的训练和推理成本显著更低。

## Abstract
Reasoning agents increasingly rely on external tools such as web search to answer complex queries. Reinforcement learning (RL) finetuning algorithms such as GRPO have improved long-form reasoning in text-only language models, particularly for coding and mathematics. Reliable tool use in multimodal agents, however, remains challenging because models must interpret text and images while integrating noisy retrieved evidence, often under sparse outcome-level supervision without explicit verification signals. We present Self-Verification via Reinforcement Learning (SVRL), an RL-only finetuning framework that trains multimodal agents to verify and filter retrieved evidence within their own reasoning traces, reducing reliance on external verifiers at inference time. SVRL also introduces a search-aware penalty that discourages unnecessary tool calls and a query-diversity reward that encourages diverse, well-formed search queries, providing fine-grained feedback on when and what to search. Finetuning Qwen-2.5-VL-7B with SVRL on only 5{,}000 visual question answering examples yields consistent gains in multi-hop VQA generalization and tool efficiency across benchmarks. Overall, SVRL narrows the gap between compact agents and much larger proprietary models while requiring substantially lower training and inference cost.

## 2. 论文提出的方法论

### 2.1 核心思想

- **自我验证**：让模型在推理轨迹中生成对检索结果的显式二元有用性评分（例如 `<verify>0,1,0,1</verify>`），并在 RL 训练中优化该评分，使模型学会自主筛选证据，推理时不再依赖外部验证器。  
- **细粒度奖励设计**：在 GRPO 目标基础上，加入与时序行为相关的搜索感知惩罚和查询多样性奖励，针对“何时搜索”和“搜索什么”提供专门学习信号。  
- **训练时使用验证器，推理时丢弃**：训练阶段利用外部验证器（GPT-5）结合真值答案标注查询和检索片段的有用性，用于监督模型的自我验证分数；推理阶段模型完全依靠自身验证能力。

### 2.2 关键技术细节

- **策略优化框架**  
  - 将模型视为随机策略 \(\pi_\theta\)，生成轨迹 \(\tau=(s_{1:T}, y)\)，其中每个步骤 \(s_t\) 包含自然语言推理 `<reason>…</reason>`、动作 \(a_t\) 及工具参数 \(p_t\)。  
  - 采用 GRPO（Group Relative Policy Optimization）估计组内相对优势，并使用 **Dr. GRPO** 变体移除可能导致梯度放大的归一化项，提高训练稳定性。

- **搜索感知惩罚（Search-Aware Penalty）**  
  - 先用预训练模型对每个训练样本做一次无工具前向传播，得到预测答案 \(\hat{y}\)；若 \(\hat{y}=y^*\)，则标记该样本为 `search_free`。  
  - 在 RL 轨迹中，若样本属于 `search_free` 且智能体仍调用搜索工具，则奖励因子设为 \(\lambda_{sa}=0.1\)，否则为 1。  
  - 该机制避免了对所有搜索调用统一惩罚的缺点，能够在抑制不必要搜索的同时保留必要搜索的激励。

- **查询多样性奖励（Query Diversity Reward）**  
  - 要求模型为每个文本搜索步骤提出 \(k\) 个候选查询（论文中 \(k=5\)），并随机执行其中一个有效、唯一的查询。  
  - 若轨迹不调用文本搜索，则 \(r_{count}=1\)；否则 \(r_{count}=\max(\epsilon, \hat{k}/k)\)，其中 \(\hat{k}\) 是实际生成的有效唯一查询数。  
  - 该奖励鼓励模型生成多个多样化、形式良好的查询，提升检索意图的准确性和证据召回质量。

- **自我验证与训练监督（Self-Verification Alignment）**  
  - 模型在工具调用后输出 `<verify>` 二进制向量，表示每个检索片段是否有助于回答当前问题。  
  - 训练时利用外部验证器（GPT-5）获取两个对齐信号：  
    - \(r_{qalign}\)：模型提出的查询候选与验证器判定“有用查询”标签的一致性。  
    - \(r_{salign}\)：模型对检索片段的自我评分与验证器判定“包含答案支持证据”标签的一致性。  
  - 这些对齐奖励仅在最终答案正确时才参与组合，防止奖励黑客（即通过堆叠塑造项获得部分信用而答错的情况）。

- **总奖励与优化目标**  
  - SVRL 因子定义为：  
    \[
    r_{svrl} = r_{aware} \cdot r_{count} \cdot r_{qalign} \cdot r_{salign}
    \]  
  - 轨迹总奖励：  
    \[
    r(\tau) = (1-\alpha) \, r_{acc}(\tau) \, r_{svrl}(\tau) + \alpha \, r_{fmt}(\tau)
    \]  
    其中 \(r_{acc}\) 为精确匹配正确性，\(r_{fmt}\) 为格式奖励，\(\alpha=0.1\)。  
  - 最终目标仍为 GRPO 的 KL 正则化最大化问题，只是将标准轨迹奖励替换为上述 \(r(\tau)\)。

### 2.3 算法流程（Algorithm 1 概要）

1. **自标注阶段**：对每个训练样本执行一次无工具前向传播，标记 `search_free` 标签。  
2. **RL 微调阶段**：  
   - 采样小批量数据，对每个输入采样 \(G\) 条轨迹（论文中 \(G=4\)）。  
   - 解析轨迹得到最终答案、工具参数和自我验证分数 \(v\)。  
   - 调用训练期验证器得到查询和片段的有用性标签 \(v^*\)。  
   - 计算 \(r_{svrl}\) 和总奖励 \(r^{(i)}\)。  
   - 使用 Dr. GRPO 更新策略参数。
