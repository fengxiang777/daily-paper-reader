## 摘要
多智能体大语言模型通过在共享环境中协调多个策略来解决复杂任务。然而，现有的强化学习方法通常分别优化每个响应或轨迹，即使多个输出共同导致一次状态转移。因此，更新单元与系统执行的动作不一致。为了解决这一问题，我们提出 SRPO（集合式相对策略优化），将活跃集合——即一次转移所消耗的最小输出集合——视为一个多智能体动作。具体而言，SRPO 将成员对数比率合并为一个按基数归一化的集合比率，分配一个相对优势，并对该集合进行一次裁剪。这种表述将分工和联合共同进化统一为不同集合大小的动作。在数学推理和多轮搜索上的实验表明，在四种模型规模上，固定、混合和动态路由工作流可使用同一训练接口，并在所报告的比较中取得了最强的宏平均结果。优化诊断进一步刻画了其在不同事件归约和集合大小下的稳定性。

## Abstract
Multi-agent large language models solve complex tasks by coordinating several policies in a shared environment. However, existing reinforcement learning methods usually optimize each response or trajectory separately, even when several outputs jointly cause one state transition. Consequently, the update unit differs from the action executed by the system. To address this problem, we propose SRPO (Setwise Relative Policy Optimization), which treats the active set the minimal set of outputs consumed by one transition, as one multi-agent action. Specifically, SRPO combines member log-ratios into one cardinality-normalized set ratio, assigns one relative advantage, and clips the set once. This formulation unifies division of labor and joint co-evolution as actions with different set sizes. Experiments on mathematical reasoning and multi-turn search demonstrate one training interface for fixed, mixed, and dynamically routed workflows across four model scales, with the strongest macro-average results among the reported comparisons. Optimization diagnostics further characterize its stability under different event reductions and set sizes.

## 2. 论文提出的方法论

### 2.1 核心思想

- 定义 **活跃集合（active set）** \(S_e\)：在一次决策事件 \(e\) 中，环境为产生下一状态而共同消耗的 **最小新采样输出集合**。
- 对应的集合值动作 \(a_e = \{a_{e,j} : j \in S_e\}\)，其中 \(K_e = |S_e|\) 为集合基数。
- 环境状态包含外部任务状态和共享编排记忆；只有被提交并被环境消耗的输出才属于动作，私有草稿不属于。
- 事件动作概率因子化为：
  \[
  \pi_\Theta(a_e \mid s_e) = \prod_{j \in S_e} q_{e,j}(a_{e,j} \mid o_{e,j})
  \]
  其中 \(q_{e,j}\) 是产生成员 \(j\) 的策略，\(\Theta\) 包含路由器、工人和聚合器的可训练参数。

### 2.2 SRPO 的四个关键操作

1. **成员对数比率**：对每个动作成员 \(j\)，计算掩码序列对数比率：
   \[
   \ell_{e,j} = \sum_u m_{e,j,u} \log \frac{q_{\text{cur}}(a_{e,j,u} \mid o_{e,j,u})}{q_{\text{old}}(a_{e,j,u} \mid o_{e,j,u})}
   \]
   其中掩码 \(m_{e,j,u} \in \{0,1\}\) 排除 prompt、padding 和环境 token。

2. **集合归一化比率**：将成员对数比率之和按 \(\sqrt{K_e}\) 归一化：
   \[
   L^{\text{set}}_e = \frac{1}{\sqrt{K_e}} \sum_{j \in S_e} \ell_{e,j}, \quad
   \rho^{\text{SRPO}}_e = \exp(L^{\text{set}}_e)
   \]
   当 \(K_e = 1\) 时退化为普通序列级似然比。方差分解为：
   \[
   \operatorname{Var}(L^{\text{set}}_e) = \sigma_e^2 + \frac{2}{K_e}\sum_{i<j} \operatorname{Cov}(\ell_{e,i}, \ell_{e,j})
   \]
   说明独立成员尺度被保留，相关成员通过协方差项显式贡献。

3. **单一优势值**：每个决策事件分配一个相对优势 \(\hat{A}_e\)，例如 group-relative 实现中：
   \[
   \hat{A}_e = \frac{R_e - \mu_{g(e)}}{\sigma_{g(e)} + \epsilon}
   \]
   其中 \(R_e\) 是下游团队回报，\(\mu_{g(e)}\)、\(\sigma_{g(e)}\) 是可比较事件组的均值和标准差。所有成员共享同一优势。

4. **集合裁剪与事件归约**：对完整集合裁剪一次，并在事件而非成员或 token 上平均：
   \[
   J_{\text{SRPO}}(\Theta) = \frac{1}{|B|} \sum_{e \in B} \min\left(\rho^{\text{SRPO}}_e \hat{A}_e,\; \operatorname{clip}(\rho^{\text{SRPO}}_e, 1-\epsilon, 1+\epsilon) \hat{A}_e\right)
   \]

### 2.3 实现机制

- 每个采样响应存储：事件标识符、预动作状态标识符、成员索引、期望基数、策略版本和行为对数概率。
- **事件原子批处理**：同一事件的所有行必须留在同一全局 mini-batch；缺失成员会使事件无效，而不是静默改变动作。
- 算法流程：识别完整事件 → 计算成员对数比率 → 归约为一个集合比率 → 用事件优势裁剪一次 → 对事件平均。

## 6. 论文的主要结论与发现

- **统一训练接口**：SRPO 可以在固定、混合和动态路由工作流中使用同一优化接口，跨四种模型规模。
- **数学推理结果**：
  - Qwen3-4B：宏 Avg@16 = \(61.3 \pm 0.5\)，宏 Pass@16 = \(77.9 \pm 0.8\)。
  - Qwen3-8B：宏 Avg@16 = \(62.5 \pm 0.5\)，宏 Pass@16 = \(77.8 \pm 0.7\)。
  - 在两种规模上均超过最强展示的 Dr. MAS 行 0.2 个百分点。
- **多轮搜索结果**：
  - Qwen2.5-3B：宏 Avg@16 = \(40.1 \pm 0.5\)，宏 Pass@16 = \(56.1 \pm 0.8\)。
  - Qwen2.5-7B：宏 Avg@16 = \(45.6 \pm 0.4\)，宏 Pass@16 = \(61.6 \pm 0.7\)。
  - 相较强 Dr. MAS 分别提升 3.2/3.1 和 1.8/3.3 个百分点。
- **消融结论**：
  - 五成员 SRPO（Sqrt）优于单例边界（K=1 Sqrt）2.9 Avg@16 和 3.7 Pass@16。
  - 在 K=5 下，Sqrt 归一化优于 None（+1.5/+1.8）和 Mean（+5.4/+7.5）。
- **训练动态**：事件均匀运行梯度范数变化更窄，显示在活动集大小变化时仍保持稳定。
- **核心原则**：“共同改变环境的输出应被共同优化”。

## 7. 优点

- **工作流无关的动作定义**：将分工、联合协同进化和混合编排统一为同一策略优化单元，解决了更新单元与执行动作不一致的问题。
- **方法简单且通用**：只增加三个操作（构造事件、归约集合比率、单次裁剪），rollout 生成、奖励设计、优势估计和优化器均可保持不变。
- **兼容现有 RL 体系**：可与 GRPO、DAPO、Search-R1 等相对策略优化方法结合，单例情况退化为普通响应级优化。
- **实验覆盖面广**：包含数学推理和多轮搜索两类任务、四种模型规模、固定/混合
