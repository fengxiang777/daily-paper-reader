## 摘要
虽然强化学习（RL）能有效激励大语言模型的推理能力，但当前流程受到训练不稳定和熵快速坍缩的制约。这些局限常源于标准采样流程中的“Rollout Silencing”和低质量梯度信号。本文提出一种稳健的、以数据为中心的框架来稳定 RL 训练。我们首先提出潜力感知查询挖掘（PAQM），动态筛选数据以聚焦“蒸馏区”——具有高能力激发潜力的样本。此外，我们提出混合分层回放（HSR），一种新机制，通过基于路径熵（一种 rollout 级置信度代理）和结果奖励对 rollouts 进行分层，从而重构批次。在每个优化步骤中，HSR 重用当前策略的“稳定锚点”和“困难负样本”来构建高对比度优化组，然后在下一步之前清空其缓冲区。该方法缓解了熵坍缩，同时在有限计算下提高学习信号的利用率。我们的方法在复杂推理任务上优于强基线，为稳定高效的 RL 微调提供了原则性解决方案。

## Abstract
While Reinforcement Learning (RL) effectively incentivizes reasoning in Large Language Models, current pipelines are hindered by training instability and rapid entropy collapse. These limitations often stem from "Rollout Silencing" and low-quality gradient signals in standard sampling procedures. In this work, we propose a robust, data-centric framework to stabilize RL training. We first introduce Potential-Aware Query Mining (PAQM), which filters data dynamically to focus on the "Distillation Zone"---samples with high potential for capability elicitation. Furthermore, we present Hybrid Stratified Replay (HSR), a novel mechanism that restructures batches by stratifying rollouts based on Path Entropy, a rollout-level confidence proxy, and outcome reward. Within each optimization step, HSR reuses current-policy "Stability Anchors" and "Hard Negatives" to construct high-contrast optimization groups, then clears its buffers before the next step. This approach mitigates entropy collapse while improving the utilization of learning signals under limited compute. Our method outperforms strong baselines on complex reasoning tasks, offering a principled solution for stable and efficient RL fine-tuning.

## 1. 论文核心问题与整体含义

- 论文针对多模态大语言模型（MLLMs）在强化学习（RL）后训练中的两个核心问题：**训练不稳定**与**熵快速坍缩（entropy collapse）**。
- 作者认为，当前 RL 流程（特别是 GRPO 等 group-based 方法）的主要不稳定来源，往往不是 RL 目标本身，而是：
  - **Rollout Silencing（rollout 沉默）**：模型在采样时过早收敛到少数高置信模式，导致有效梯度信号消失；
  - **低质量优化组**：随机采样组成的 group 可能出现 **reward-degenerate group（奖励退化组）**——组内所有样本奖励相同，advantage 方差趋近于零，更新无效或噪声过大。
- 这一现象在长链推理（long-CoT）中尤为严重，因为奖励信号稀疏、延迟，策略容易陷入局部最优。
- 论文的核心思想是：**不修改 RL 优化目标，而是从“数据/样本组成”的角度控制优化器每个步骤看到什么**，从而稳定训练过程。

## 2. 方法论：核心思想与关键技术细节

论文提出 **Stable-MM-R1**，一个以数据为中心的稳定训练框架，分为三个阶段（Phase 0–2），其中 Phase 1 和 Phase 2 共同构成 **HSR（Hybrid Stratified Replay）**。

### 2.1 Phase 0：Potential-Aware Query Mining（PAQM，潜力感知查询挖掘）

- 目标：动态构建课程（curriculum），让模型持续在 **Distillation Zone（可学习区）** 中训练，避免浪费算力在过于简单或过于困难的问题上。
- **Learnability 定义**：对每个 query \(x\)，用当前策略 \(\pi_\theta\) 采样 \(N=16\) 条 rollouts，计算经验成功率 \(\hat{p}(x)\)。
- 根据 \(\hat{p}(x)\) 将 query 分为三类：
  - **Distillation Zone**：\(0 < \hat{p}(x) < 1\)，模型“会但不稳定”，是理想训练目标；
  - **Trivial Zone**：\(\hat{p}(x)=1\)，已掌握，降采样防止过拟合；
  - **Impossible Zone**：\(\hat{p}(x)=0\)，生成零梯度，需要诊断。
- **Path Entropy（路径熵）**：定义为 rollout 级、长度归一化的序列 surprisal：
  \[
  H_{\text{path}}(y|x) = -\frac{1}{|y|}\sum_{t=1}^{|y|}\log \pi_\theta(y_t|x,y_{<t})
  \]
  作为模型对单条 rollout 的置信度代理（注意：不是完整预测分布的 Shannon 熵，也不是直接估计认知不确定性）。
- **Modality-Decoupled Diagnosis（模态解耦诊断）**：
  - 对 Impossible Zone 中的 query，用 ground-truth caption 做 text-only 探针，区分：
    - **感知缺陷（Perceptual Deficit）**：模型能回答纯文本探针，则注入 **Visual Decomposition Hint**（如坐标、形状）；
    - **认知缺陷（Cognitive Deficit）**：模型无法回答探针，则注入 **Key Reasoning Node**（如定理第一步）。
  - 这些 hints 来自专有教师模型 **Seed-1.5-VL**，离线缓存，仅在 Phase 0 课程构建时使用；约 30% 的困难 query 被回收到 Distillation Zone。

### 2.2 Phase 1：Diagnostic Path-Entropy–Reward Stratification（路径熵-奖励分层）

- 对当前 global batch 中所有 rollouts，计算每条样本的：
  - 结果奖励 \(r(y)\)（0 或 1）；
  - Path Entropy \(H_{\text{path}}(y|x)\)。
- 使用 **Dynamic Percentile Thresholding**：以当前 batch 的 Path Entropy 分布的 10th 和 90th 百分位作为动态阈值 \(\tau_{\text{low}}, \tau_{\text{high}}\)。
- 将 rollouts 分为三个缓冲区：
  - **Stability Anchors（稳锚，\(B_{\text{anc}}\)）**：\(r=1\) 且 \(H<\tau_{\text{low}}\)，高置信正确样本；
  - **Hard Negatives（困难负样本，\(B_{\text{neg}}\)）**：\(r=0\) 且 \(H<\tau_{\text{low}}\)，高置信错误样本；
  - **Epiphanies（顿悟样本，\(B_{\text{epi}}\)）**：\(r=1\) 且 \(H>\tau_{\text{high}}\)，低置信但正确，作为重点学习目标。
- “Confusion Zone”（\(r=0\) 且 \(H>\tau_{\text{high}}\)）样本被过滤出有效池。

### 2.3 Phase 2：Hybrid Group Assembly（混合组装配）

- 将每个 query 的最终优化组预算 \(G=16\) 分成两个流：
  - **Stream A：Structured Stabilization（结构化稳定流，50%）**：
    - 按 50% Epiphanies、25% Stability Anchors、25% Hard Negatives 的比例从缓冲区采样；
    - 若某个配额无法满足，则释放该配额并用自然 on-policy 采样填充。
    - 目的是在微批次内构造高对比度样本，降低优势方差消失的风险。
  - **Stream B：Natural Generalization（自然泛化流，50%）**：
    - 从有效样本池（排除噪声样本）中均匀采样，保留自然 on-policy 分布，防止过拟合到人工拓扑结构。
- **Intra-Step Replay（步内回放）**：
  - 缓冲区 \(B_{\text{anc}}, B_{\text{neg}}, B_{\text{epi}}\) 的生命周期 \(\tau=1\)，即只由当前优化步骤生成的 rollouts 填充，梯度计算后立即清空。
  - 因此所有“重用”样本都来自当前策略 \(\pi_\theta\)，保持 on-policy 一致性，无需重要性采样校正。

### 2.4 理论动机

- 在二值奖励情形下，随机采样组发生退化（所有 reward 相同）的概率为：
  \[
  P_{\text{degen}} = p_\theta(x)^G + (1-p_\theta(x))^G
  \]
  当策略成功率接近 0 或 1 时，退化概率增大。
- 若结构化组中同时包含至少一个正样本（Anchor）和一个负样本（Hard Negative），则组内经验奖励方差严格为正，避免零方差导致的梯度消失。
- 论文强调这一分析是条件性的，不代表每个步骤都保证非零更新。

## 3. 实验设计

### 3.1 训练数据与场景

- **RL Prompt Corpus**：约 189k 样本，来自：
  - Geometry3K；
  - MM-Eureka 的 curator 子集；
  - ViRL39K（大规模可验证视觉推理数据）。
- 训练方式：**RL-only 参数更新**，无监督冷启动；教师 hints 只影响选中 prompt，不用于监督参数更新。
- 基础模型：**Qwen2.5-VL-7B-Instruct**；冻结 vision encoder，只更新 LLM backbone。
- 还训练了 **Stable-MM-R1-3B** 变体，用于与 3B 规模模型比较。

### 3.2 评估 Benchmark

包括 10 个多模态推理基准：

- 数学推理：MathVerse-V、MathVision、MathVista、DynaMath-W、WeMath-S；
- 逻辑/理解：LogicVista、MMMU、MMMU-Pro；
- 图表/视觉：CharXiv、MMStar。

评估指标：**Pass@8**（8 条独立响应多数投票准确率）。

### 3.3 对比方法

- **闭源参考模型**：GPT-4.1、Gemini-2.5-Pro-Thinking、Claude-4-Sonnet、Doubao-1.5-Thinking-Vision-Pro。
- **3B 开源模型**：Qwen2.5-VL-3B-Instruct、VLAA-Thinker-3B、FAST-3B。
- **7B 开源模型**：Qwen2.5-VL-7B-Instruct、VLAA-Thinker-7B、ThinkLite-7B-VL、OpenVLThinker-1.2-7B、VL-Rethinker-7B、MMR1-Math-v0、MM-Eureka-Qwen-7B、Vision-G1。
- **消融基线**：GRPO、DAPO、+PAQM、+HSR、Full Stable-MM-R1。

### 3.4 训练与评估设置

- 框架：EasyR1；
- global batch size = 128；
- 学习率 = \(1\times10^{-6}\)；
- rollout temperature = 1.0；
- 每 query 生成 \(N=16\) 条 rollouts；
- 梯度更新步数约 400；
- 控制各内部方法最终组大小 \(G=16\) 与更新次数一致；
- 由于 GRPO/DAPO 在训练后期常出现熵坍缩，论文报告这些基线 **在坍缩前的峰值性能** 作为比较，而非最终收敛 checkpoint。
