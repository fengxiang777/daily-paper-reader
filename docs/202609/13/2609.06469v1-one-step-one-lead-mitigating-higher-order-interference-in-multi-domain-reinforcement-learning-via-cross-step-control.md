## 摘要
跨多个领域的强化学习（RL）可以拓展大语言模型（LLMs）的推理能力，但联合训练常常会降低单个领域的性能，并可能破坏优化的稳定性。现有工作通常从单步视角、利用一阶梯度对齐或基于曲率的代理指标来诊断此类干扰。我们表明，这种视角可能遗漏一种关键的时序干扰：即使同一点的领域梯度几乎正交，连续的实际更新仍可能在输出空间中部分相互逆转。我们进一步表明，连续的 token 对数概率足迹可以直接从相邻检查点恢复这种交互，将其作为输出空间中的局部二阶交互，而无需显式重建同一步的曲率。基于这一见解，我们提出 OSOL，它在每次迭代中指定一个焦点领域，利用前一检查点的足迹对 token 级反弹风险进行排序，并在标准 GRPO 更新中施加按漂移排序、自适应缩放的修正。我们的分析表明，该修正抑制了目标跨步输出回退分量。受控研究进一步表明，与同点梯度诊断相比，跨步回退与后续任务损伤的关联更强；同时，前一足迹对未来反弹风险的排序比基于 Hessian 的代理指标更准确。在 Qwen3-30B-A3B 上，OSOL 达到 0.4822 的领域宏平均，比最强对比基线提高 5.7%，且无需显式高阶微分。

## Abstract
Reinforcement learning (RL) across multiple domains can broaden the reasoning capabilities of large language models (LLMs), yet joint training often degrades individual-domain performance and can destabilize optimization. Existing work typically diagnoses such interference from a single-step view using first-order gradient alignment or curvature-based proxies. We show that this view can miss a critical form of sequential interference: same-point domain gradients may remain nearly orthogonal even when consecutive realized updates partially reverse one another in output space. We further show that consecutive token log-probability footprints recover this interaction directly from adjacent checkpoints as a local second-order interaction in output space, without explicitly reconstructing same-step curvature. Building on this insight, we propose OSOL, which designates a focus domain at each iteration, uses the preceding checkpoint footprint to rank token-level rebound risk, and applies a drift-ranked, adaptively scaled correction within the standard GRPO update. Our analysis shows that this correction suppresses the targeted cross-step output backtracking component. Controlled studies further show that cross-step backtracking is more strongly associated with subsequent task damage than same-point gradient diagnostics, while the preceding footprint ranks future rebound risk more accurately than Hessian-based proxies. On Qwen3-30B-A3B, OSOL reaches a domain-macro average of 0.4822, improving by 5.7% over the strongest compared baseline, without explicit higher-order differentiation.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

**核心思想：一步一主导（One Step, One Lead）**
- 每一次混合领域更新中指定一个**焦点领域（focus domain）**，该领域获得更大的任务权重，并且只有该领域的合格响应 token 受到历史修正；非焦点领域保留较小权重但仍在同一更新中。
- 使用**前一检查点的 token 级对数概率漂移**来识别下一次更新中可能发生“负向到正向反弹”的 token，并在标准 GRPO 系数上添加一个非正、按漂移排序、自适应缩放的修正项，以抑制跨步输出回溯。

**关键技术细节**
- **Token 对数概率足迹**：对固定响应 token 坐标 $(x_i,a_i)$ 定义向量 $\ell_k(\theta)=[\log\pi_\theta(a_i|x_i)]$。连续更新产生前一步足迹 $u=\ell_k(\theta_k)-\ell_k(\theta_{k-1})$ 和当前基础足迹 $d_0=\ell_k(\theta^0_{k+1})-\ell_k(\theta_k)$。
- **输出 KL 与 Fisher 几何**：定义焦点域 token 上下文上的输出 KL $D_k(\delta)$。引理 1 证明 $D_k(\delta)$ 在 $\delta=0$ 处的 Hessian 为**输出 Fisher 矩阵** $\bar F_k$；定理 1 证明在 $O(\eta)$ 步长下，$\frac{1}{N}u^\top d_0=\delta_{k-1}^\top F_k\delta^0_k+O(\eta^3)$，其中 $F_k$ 为经验输出 Fisher。
- **回溯定义**：定义回溯量 $\Gamma(u,d)=-\frac{1}{N}u^\top d$，以及**负向到正向受控回溯质量** $B_-(u,d)=\frac{1}{N}\sum_{i:u_i<0}(-u_i)[d_i]_+$，即前一更新降低、当前更新升高的 token 概率质量。
- **OSOL 修正构造**：
  1. 对焦点域中满足非零轨迹级优势的响应 token 计算 $u_i$，取负漂移候选集 $C_k=\{i:u_i<0\}$。
  2. 对 $C_k$ 内 token 按 $u_i$ 升序排列，将分位数映射到 $[r_{\min},r_{\max}]$（默认 $-1$ 到 $0$），越负的漂移惩罚越强。
  3. 自适应缩放：令 $q_i$ 为支持剖面，设置 $\kappa_k=\tau\,\mathrm{std}_{E_k}(A^{\mathrm{base}})/\mathrm{std}_{E_k}(q)$，其中 $A^{\mathrm{base}}$ 为任务加权的 GRPO 基础系数，默认 $\tau=0.03$，使得残差标准差保持在基础系数标准差的一个受控比例。
  4. 最终系数 $\tilde A_i=\mathrm{clip}(A^{\mathrm{base}}_i+r^{\mathrm{OSOL}}_i,-3,3)$，并用标准 PPO 截断代理目标进行优化。
- **理论保证**：引理 2 表明该修正等价于 PPO 锚点上的历史条件似然比惩罚；引理 3 和命题 1 证明在局部主导条件下，非正系数修正能传递到输出空间并收缩 $B_-$ 分量。

- **同点一阶梯度诊断不足**：全局梯度冲突（Spearman $\rho_s=-0.19$）和模块级冲突（$\rho_s=-0.22$）与后续任务损伤没有正相关，而跨步回溯质量相关性为 $\rho_s=0.40$（95% bootstrap CI [0.05,0.69]）。

## 7. 优点：方法或实验设计上有哪些亮点

- **新颖的跨步视角**：将干扰分析从单点梯度/曲率转移到连续更新的输出空间交互，更有针对性地捕捉时序上的能力回退。
- **理论与实现闭环**：从输出 KL 几何、checkpoint 足迹与 Fisher 的二元性，到非正系数的回溯收缩证明，理论链完整；且实际只需前一检查点，计算开销低。
- **无需显式高阶微分或辅助模型**：仅利用已经保存的前一 checkpoint 重新打分，不引入 Hessian 估计、辅助专家模型或额外奖励信号。
- **token 级精细控制**：在焦点域内对 token 按负漂移排名分配惩罚，比响应级或随机分配更精准；自适应缩放保持残差相对当前系数尺度的稳定性。
- **多层面实验验证**：包含大规模主实验、多组消融、受控诊断统计和机制分析，证据较全面。
- **领域宏平均指标设计合理**：避免基准数量不同导致的权重失衡，增强了跨领域公平性。

## 8. 不足与局限：包括实验覆盖、偏差风险、应用限制等

- **实验规模与可重复性受限**：主实验只有两个骨干模型，未见多随机种子方差或置信区间；训练细节中无 GPU 型号/数量/时长，难以评估实际算力需求和基线公平性。
