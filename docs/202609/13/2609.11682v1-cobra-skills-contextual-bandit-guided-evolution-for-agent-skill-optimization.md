## 摘要
大语言模型（LLM）智能体能够从先前任务经验中提炼的可复用技能中获益，但现有技能优化方法往往依赖昂贵的基于执行的评估和大量任务数据。我们提出了 COBRA-Skills，一个高效框架，将技能优化形式化为在动态演化的候选空间上的预算化序贯优化。COBRA-Skills 将上下文赌博机引导的优先级排序与基于证据的技能进化相结合，选择性地将评估分配给有前景或信息丰富的候选技能，同时根据执行反馈持续改进技能群体。在六个异构智能体基准和三个目标模型上，COBRA-Skills 在所比较的方法中始终取得最强的平均性能，同时相较于 SkillOpt 将优化成本降低 55–58%，并且每个基准仅使用 50 个独特的优化示例。进一步分析表明，COBRA-Skills 对智能体框架的变化保持鲁棒性，并且当使用目标模型本身进行技能生成与改进时仍能有效运行。

## Abstract
Large language model (LLM) agents can benefit from reusable skills distilled from prior task experience, yet existing skill optimization methods often rely on costly execution-based evaluation and substantial task data. We introduce \textbf{COBRA-Skills}, an efficient framework that formulates skill optimization as budgeted sequential optimization over a dynamically evolving candidate space. COBRA-Skills couples contextual-bandit-guided prioritization with evidence-grounded skill evolution, selectively allocating evaluations to promising or informative candidates while continually refining the skill population from execution feedback. Across six heterogeneous agent benchmarks and three target models, COBRA-Skills consistently achieves the strongest average performance among compared methods, while reducing optimization cost by 55--58\% relative to SkillOpt and using only 50 unique optimization examples per benchmark. Further analyses show that COBRA-Skills remains robust to changes in the agent harness and performs effectively when the target model itself is used for skill generation and refinement.

## 1. 核心问题与研究背景

- LLM 智能体在大量任务中会反复遇到相似目标、流程、工具与失败模式，因此可复用“技能”（skill）被认为是一种轻量级的知识沉淀方式，能注入上下文以提升下游任务表现。
- 但获取高质量技能存在困难：
  - 人工编写成本高、依赖领域专家；
  - 直接从 LLM 参数知识生成技能可能“看似合理但不可靠”，未必能提升实际性能；
  - 近年方法开始基于真实执行轨迹与执行反馈来构建技能，并采用迭代进化式生成、修改与选择。
- 这些执行反馈驱动的方法虽质量更高，但带来两个效率瓶颈：
  - **候选技能评估昂贵**：需要通过目标智能体在任务或验证集上实际执行才能得知效用，容易把预算浪费在低质量候选项上；

- 因此核心问题是：**在有限计算预算与有限任务样例下，如何选择性分配候选评估，并高效复用执行反馈来持续改进技能**。

## 2. 方法论

COBRA-Skills 将技能优化形式化为**预算化序贯优化**问题，并建立“上下文赌博机优先级排序 + 证据驱动技能进化”的闭环。

### 2.1 问题形式化

- 给定小型优化集 \(D_{opt}\subset D\)，初始无技能轨迹 \(T_0\)，以及有限优化轮数 \(T\)。
- 候选技能通过执行反馈不断生成、修改、评估。
- 优化目标是找到一个技能 \(s^\star\)，最大化在未知测试分布上的泛化指标：
  \[
  s^\star = \arg\max_{s\in S_T} \mathbb{E}_{(x,y)\sim D}\left[\text{Metric}(A(x;s), y)\right]
  \]
  其中 \(A(x;s)\) 表示目标智能体配备技能 \(s\) 后对输入 \(x\) 的输出。

### 2.2 总体流程

- 维护固定大小的候选技能种群 \(P_t\)。
- 使用上下文赌博机对种群中的技能打分，选择最高分技能交给目标智能体评估。
- 将执行反馈与奖励记入历史 \(H_t\)。
- 周期性触发种群进化：删除低优先技能，用进化算子的新候选补齐。
- 教学模型 \(M_{teach}\) 负责从证据中生成和修改技能；候选评分仅来自目标智能体执行反馈，避免教学模型主观评分。

### 2.3 上下文赌博机引导的优先级排序

- **技能表示**：用固定嵌入模型 \(\phi\) 将技能文本映射为语义向量 \(z_s=\phi(s)\)，论文中使用 Qwen3-Embedding-4B。
- **奖励预测**：一个轻量两层 MLP \(f_\theta\)（隐藏层 64，ReLU，输出标量）基于历史评估数据拟合，预测候选技能的奖励。
  - 损失函数为 MSE 加 L2 正则：
    \[
    L(\theta)=\frac{1}{|H_t|}\sum_{(s_i,z_i,r_i)\in H_t}(f_\theta(z_i)-r_i)^2+\beta\|\theta\|_2^2
    \]
- **不确定性探索项**：采用 LinearUCB 风格置信度奖励：
  \[
  b_t(z_s)=\nu\sqrt{z_s^\top A_{t-1}^{-1} z_s}
  \]
  其中 \(A_{t-1}=\lambda I+\sum_{i=1}^{t-1} z_{s_i}z_{s_i}^\top\) 是历史评估嵌入构成的正则化设计矩阵。
- **最终优先级分数**：
  \[
  U_t(s)=f_{\theta_{t-1}}(z_s)+b_t(z_s)
  \]
  - 每轮选择最高 \(U_t(s)\) 的技能执行；
  - 种群更新时也使用该分数剪除“低利用价值 + 低探索价值”的技能。

### 2.4 证据驱动技能进化

种群更新周期由轮次间隔 \(d\) 和对数阈值 \(\eta\) 控制，触发后剪掉优先分最低的 \(m\) 个技能，并用以下三个算子补充：

- **Regeneration（再生）**
  - 从原始无技能轨迹 \(T_0\) 中独立生成新技能；
  - 不依赖父技能，可引入新搜索方向，维持种群多样性。

- **Rollout Mutation（轨迹变异）**
  - 基于当前轮被评估技能产生的成功/失败轨迹，对该父技能做局部、保守修改；
  - 直接将赌博机选择的评估与证据驱动局部精化连接起来。

- **Crossover（交叉）**
  - 在历史中已评估技能足够多时启用；
  - 将技能按表现分为高分组和低分组；
  - 选择高分技能作为 backbone，另一高分技能提供正证据，低分技能作为负证据；
  - 不简单拼接父技能，而是进行基于性能证据的重组；且不需要额外目标智能体轨迹。

### 2.5 关键超参数

- 优化轮数 \(T=30\)，种群大小 \(K=10\)，每次进化剪除 \(m=3\) 个技能；
- 初始种群由 10 个独立再生技能构成；
- 每次评估使用完整 50 个优化示例；
- Crossover 在超过 8 个不同技能被评估后启用；
  - 此前算子比例 Regeneration : Rollout Mutation : Crossover = 2:1:0；
  - 此后为 1:1:1；
- 探索系数 \(\nu=0.1\)，进化参数 \(d=3\)，\(\eta=0.35\)，LinearUCB 正则 \(\lambda=0.03\)。

## 6. 主要结论与发现

- COBRA-Skills 在所有三个目标模型、所有六个基准上，平均性能最高。
- 相较无技能基线，平均性能提升：
  - Qwen3.6-35B-A3B：+13.1 个百分点；
  - GPT-5.4-Nano：+26.9 个百分点；
  - Gemma-4-26B-A4B-it：+22.5 个百分点。
- 相较 SkillOpt：
  - 总优化成本降低 55%–58%；
  - 每提升 1 个百分点的成本降低 60%–69%；
  - 每个基准仅使用 50 个独特优化示例。
- 成本优势主要来自教学模型 token 使用量大幅下降：COBRA-Skills 比 SkillOpt 少 67%–80%。
- 外部 harness 实验表明性能提升不依赖特定执行接口。
- 自教学实验表明：即使教学模型与目标模型相同，COBRA-Skills 仍能保持较强性能，且成本约减半。
- 跨模型迁移显示大多数优化技能可以跨模型迁移并带来正收益，说明技能捕捉的是任务级策略而非仅针对单一目标模型。
- 消融表明：
  - Bandit 优先级排序与种群进化两个组件具有互补作用；
  - 性能提升不是简单来自“更多候选技能然后选最好”。

- **超参数较多且调优成本未计入**：包含探索系数、进化周期、种群大小、剪除数量、正则系数等，实际调优可能带来额外开销，论文未报告这些调优成本。  
- **教学模型依赖仍然存在**：虽然教学模型 token 使用量大幅下降，但方法仍需要一个较强的大模型来生成和修改技能，完全消除外部模型成本仍有距离。  
- **基准排除可能影响完整性**：OfficeQA 因复现失败被排除，虽给出了说明，但降低了对方法在更多场景下有效性的说服力。

## 9. 总结与评价

COBRA-Skills 针对 LLM 智能体技能优化中“候选评估昂贵”与“技能改写昂贵”两大瓶颈，提出了预算化序贯优化框架，将上下文赌博机优先级排序与证据驱动技能进化有机结合。该方法在六个异构基准、三个目标模型上均取得显著性能提升，同时大幅降低总体优化成本，展现出良好的效率与泛化能力。

从方法设计看，COBRA-Skills 的核心贡献在于：

1. **选择性评估机制**：通过 LinearUCB 风格的奖励预测与不确定性探索，避免在低质量候选上浪费执行预算；  
2. **证据驱动进化算子**：再生、轨迹变异与交叉均基于真实执行反馈，兼顾多样性与局部精化，避免对有效技能的大幅破坏；  
3. **成本控制**：减少教学模型调用次数，使技能优化在有限预算下更具实用性。

总体而言，COBRA-Skills 为技能优化提供了一种高效、可扩展的解决方案，尤其在计算预算受限的实际场景中具有较高应用价值。未来工作可进一步探索更灵活的预算分配策略、自适应技能表示、跨任务技能库构建以及更全面的统计验证，以增强方法的鲁棒性与普适性。
