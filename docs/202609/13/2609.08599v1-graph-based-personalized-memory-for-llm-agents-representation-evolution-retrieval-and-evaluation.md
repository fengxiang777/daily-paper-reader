## 摘要
大语言模型（LLM）智能体正从单次会话工具向长期个人助手演进，必须在不同任务、情境和交互中适配个体用户。这一转变使记忆成为个性化的核心需求，因为用户偏好、目标、约束、关系和过往经历是逐步积累的，并且往往随时间变化。基于图的个性化记忆通过显式关系、时间上下文和证据链接，为建模此类用户信息提供了结构化方式。这类表示不仅能建模智能体对用户记住了什么，还能建模记忆如何被连接、修正和检索，以支持个性化决策。然而，现有工作分散在个性化智能体和通用图记忆框架之间，难以从整体上理解设计空间。本综述以生命周期视角梳理面向LLM智能体的基于图的个性化记忆。我们围绕记忆表示、记忆演化、记忆检索和记忆评估组织现有研究。我们进一步比较关键设计选择，讨论当前评估实践，并指出构建可靠的长期个性化智能体的开放性挑战。本综述旨在阐明基于图的记忆如何支持自适应、可控且以用户为中心的LLM智能体。

## Abstract
Large Language Model (LLM) agents are evolving from single-session tools toward long-term personal assistants that must adapt to individual users across tasks, contexts, and interactions. This shift makes memory a core requirement for personalization, since user preferences, goals, constraints, relationships, and past experiences are accumulated gradually and often change over time. Graph-based personalized memory provides a structured way to model such user information through explicit relations, temporal context, and evidence links. Such representations can model not only what an agent remembers about a user but also how memories are connected, revised, and retrieved to support personalized decisions. However, existing work remains fragmented across personalized agents and generic graph memory frameworks, making it difficult to understand the design space as a whole. This survey develops a lifecycle-oriented view of graph-based personalized memory for LLM agents. We organize existing studies around memory representation, memory evolution, memory retrieval, and memory evaluation. We further compare key design choices, discuss current evaluation practices, and open challenges in building reliable long-term personalized agents. This survey aims to clarify how graph-based memory can support adaptive, controllable, and user-centric LLM agents.

## 2. 论文提出的方法论

本文未提出新的算法或模型，而是提出一套**分类体系和生命周期分析框架**，用于系统化理解已有工作。

- **生命周期四阶段框架**  
  - **记忆表示（Representation）**：图如何建模用户信息。  
  - **记忆演化（Evolution）**：图如何随新证据更新、冲突消解、压缩、删除。  
  - **记忆检索（Retrieval）**：如何从图中取出当前任务所需的用户证据。  
  - **记忆评估（Evaluation）**：如何衡量上述环节的质量。

- **个人记忆五维度**  
  - 语义（Semantic）：稳定事实、偏好、目标、约束。  
  - 时间（Temporal）：记忆何时有效、如何变化。  
  - 关系（Relational）：与人物、地点、任务、物品的关联。  
  - 经验（Experiential）：过去事件、结果、习惯、例行行为。  
  - 情感（Affective）：情绪效价与强度，如满意、沮丧。  
  - 这些维度用于界定“图必须表示什么”，后续表示与检索均围绕它们展开。

- **记忆表示层次**  
  - **元素层**：  
    - 节点角色：证据节点、事实节点、抽象节点、领域专用节点。  
    - 关系类型：时间关系、溯源关系、关联关系、领域专用关系。  
    - 生命周期元数据：时间戳、有效区间、失效标记等。  
  - **结构层**：将系统分为五种图模式。  
    - 扁平图（Flat Graph）：如 UMGR、KGT、Mem0g。  
    - 层次图（Hierarchical Graph）：如 GAAMA、Bi-Mem、GAM、SGMem。  
    - 超图（Hypergraph）：如 HingeMem、HyperMem。  
    - 混合图（Hybrid Graph）：图 + 树/摘要库/证据缓冲，如 H-Mem、LiCoMemory、MemWeaver。  
    - 多分离图（Multiple Disjoint Graphs）：如 DEMENTIA-PLAN，但证据有限。

- **记忆演化操作**  
  - **准入（Admission）**：决定新证据是否进入持久记忆及其类型和粒度，如 KGT、MemORAI、MemGuard。  
  - **整合（Integration）**：将新证据局部写入图结构，如追加溯源链接、节点复用、缓冲写入等，如 LiCoMemory、Mem0g、HingeMem、GAM。  
  - **冲突消解（Conflict Resolution）**：区分三类冲突——时间取代、用户纠错、情境共存；不应简单“最新即正确”，如 AriadneMem、GRAVITY、ZEP。  
  - **整合压缩（Consolidation）**：多轮写入后重组记忆，服务抽象、去重、重构、归档，如 GAM、All-Mem。  
  - **移除（Removal）**：区分“遗忘”（降低曝光/分辨率但保留表示，如 ScrapMem）与“删除”（改变可恢复性，如 Kumiho 的版本化信念修订）。

- **记忆检索机制**  
  - **相似性检索**：词法、关键词、稠密向量匹配，用于初始候选生成或图锚定，如 EMG-RAG。  
  - **结构检索**：利用图谱关系、抽象层级、时间视图扩展证据，如 GAM、MAGMA、AssoMem、xMemory。  
  - **自适应/智能体检索**：根据查询意图和中间证据动态调整查询解释、图探索路径、停止条件和压缩策略，如 MRAgent、PRISM、HingeMem、APEX-MEM。  
  - 检索流水线常组合三种机制：相似性锚定 → 结构扩展 → 自适应选择/压缩。

## 6. 主要结论与发现

- 图记忆相较扁平日志、摘要、向量库，能显式表达用户信息的**关联、溯源、时间变化和矛盾**，更贴合个性化场景。  
- 表示是演化和检索的**基础**：证据丰富的设计可追溯、可纠错，事实/抽象中心的设计更紧凑但可能传播抽取错误。  
- 演化不是简单“写入—覆盖”，而是**准入、整合、冲突消解、整合压缩、移除**的组合；应区分遗忘与删除，并保持历史证据与当前活跃状态之间的依赖一致性。  
- 检索通常需要**相似性锚定 + 结构扩展 + 自适应压缩**的流水线；图结构本身不能保证更好的检索，必须与有意义的用户关系、有效演化和精准检索配合。  
- 当前评估仍偏向下游任务：基准主要观察最终答案是否正确，**图质量、用户控制、生命周期有效性和真实个性化仍是评估缺口**。  
- 未来方向包括：可扩展终身记忆、多模态图记忆、因果与反事实用户建模。
