## 摘要
后置稀疏注意力通过将每个查询路由到少量 token 级交互来加速长上下文预填充。然而，硬选择对每个被省略的块赋予零概率：路由遗漏无法恢复，而固定扩展预算在简单查询和模糊查询上花费相同的工作量。我们提出了粗到细的误差感知动态注意力路由（CEDAR），这是一种保持语言模型冻结并同时保留全局覆盖的从粗到细方法。每个语义块向残差注意力路径贡献一个廉价的键值摘要；随后，估计近似误差较高的块被扩展为精确 token 注意力。精确贡献与摘要贡献在单个 softmax 归一化中合并，因此细化替换而非复制粗略证据。我们推导了由块内键/值离散度决定的输出误差界，并利用该误差界分配可变细化预算。一项受控的聚类注意力研究表明，在相同精确块预算下，残差摘要相比硬丢弃将重构误差降低超过 98%。在长上下文基准上的实验表明，CEDAR 恢复了硬稀疏路由损失的大部分质量，同时在 128K 上下文下保持约 3 倍内核加速。

## Abstract
Post-hoc sparse attention accelerates long-context prefill by routing each query to a small set of token-level interactions. Hard selection, however, assigns zero probability to every omitted chunk: a routing miss cannot be recovered, and a fixed expansion budget spends the same work on easy and ambiguous queries. We introduce Coarse-to-fine Error-aware Dynamic Attention Routing (CEDAR), a coarse-to-fine method that keeps the language model frozen while preserving global coverage. Each semantic chunk contributes a cheap key--value summary to a residual attention path; chunks with high estimated approximation error are then expanded to exact token attention. Exact and summarized contributions are combined in a single softmax normalization, so refinement replaces, rather than duplicates, coarse evidence. We derive an output-error bound governed by within-chunk key/value dispersion and use it to allocate a variable refinement budget. A controlled clustered-attention study shows that residual summaries reduce reconstruction error by more than 98% relative to hard dropping at equal exact-chunk budgets. Experiments on long-context benchmarks demonstrate that CEDAR recovers most of the quality lost by hard sparse routing while maintaining approximately $3\times$ kernel speedup at 128K context.

# CEDAR 论文总结

## 1. 论文的核心问题与整体含义

- **研究背景**：长上下文大语言模型在书籍、代码仓库、多文档证据等场景中日益重要，但标准 softmax 注意力因每个查询都要与所有历史 key 交互而计算昂贵。
- **现有方法的问题**：后处理稀疏注意力（如 DHSA、MInference、Block-Sparse）通过把每个查询路由到少量 token 来加速 prefill，但硬选择会把未选中块的概率直接置零，存在两个主要失效模式：
  - **硬省略不可恢复**：一旦路由遗漏一个中等相关的块，该块既不贡献概率也不贡献 value，误差无法弥补。
  - **固定预算不区分难度**：对简单查询和模糊查询分配相同的精确计算预算，容易查询被过度服务，困难查询则可能细化不足。
- **整体含义**：CEDAR 旨在不修改冻结语言模型的前提下，用“残差摘要路径”替代“硬丢弃”，让每个语义块始终以低成本保持全局可见，同时通过误差感知机制动态分配精确注意力预算，从而在质量与效率之间取得更好平衡。

## 2. 论文提出的方法论

- **核心思想**：粗到细、误差感知的动态注意力路由。语义块既作为路由单元，也作为可压缩单元；所有未细化块用 key–value 摘要表示，只有估计误差高的块才被扩展为精确 token 注意力，并在同一个 softmax 中合并两类贡献。
- **关键技术细节**：
  - **语义块摘要**：对每个语义块 \(C_c\)，用前缀和在线性时间内计算平均 key \(\bar{k}_c\)、平均 value \(\bar{v}_c\)，并用块长度 \(n_c\) 做长度修正，得到摘要 logit：\(\ell_{ic}^{sum} = q_i^\top \bar{k}_c/\tau + \log n_c\)。
  - **混合精确–摘要注意力**：精确细化块只通过原始 token 参与；未细化块只通过摘要参与。同一 softmax 分母同时包含精确 token logits 和摘要 logits，因此“细化替换、而非重复”粗略证据。
  - **误差感知细化优先级**：用块内 key 和 value 的离散度（\(r_k^c, r_v^c\)）结合查询范数构造 logit-radius 界 \(\epsilon_{ic}\)，优先级分数为 \(\pi_{ic} = e^{\ell_{ic}^{sum}}[(e^{\epsilon_{ic}}-1)(\|\bar{v}_c\|_2+\rho_i)+e^{\epsilon_{ic}}r_v^c]\)，同时考虑块的重要性与内部异质性。
  - **输出误差界**：推导出混合输出与稠密注意力输出的误差上界，该上界对已细化块为零、随摘要质量增加、随 key/value 离散度增加，并且可跨未细化块加法分解。
  - **系统实现**：将摘要 logits 作为额外 tile 接入 FlashAttention 风格的在线 softmax 状态更新，无需物化注意力矩阵；查询分块、segmented top-K 或阈值选择、预算向上取整到执行桶，以平衡负载；支持 GQA 按 KV head 共享摘要。
- **公式/算法流程（文字描述）**：
  1. 用 DHSA 的内容感知边界预测器将前缀划分为语义块。
  2. 对每个 KV head 计算块级 key、value 前缀和及离散度统计，得到每个块的摘要。
  3. 对每个查询块计算摘要 logit 和误差感知优先级。
  4. 强制当前块、局部窗口和 sink 区域进入精确集；其余块按优先级降序细化，直到残差误差低于阈值或达到最大精确 token 预算。
  5. 将精确 token tile 和摘要 tile 按同一在线 softmax 状态更新，输出归一化结果。

## 6. 论文的主要结论与发现

- **受控实验**：在相同精确块预算下，CEDAR 的残差摘要相比硬丢弃将重构误差降低 **98.5%–99.7%**（噪声水平 \(\sigma=0.15\) 时），证明全局摘要覆盖能有效避免硬路由遗漏。
- **长上下文质量**：在 6.25% 精确密度下，CEDAR 将 RULER 分数从 DHSA 的 79.3 恢复到 87.1，接近稠密 89.3；LongBench 为 37.0，略高于稠密 35.7 和 DHSA 36.7。在 12.5% 密度下接近或略优于稠密性能。
- **效率**：128K 上下文下 attention kernel 延迟约 224 ms，相对稠密 FA2 达到 **3.02× 加速**；相对 DHSA 增加约 13% 延迟，但质量显著提升。
- **自适应行为**：在相同误差阈值下，实际精确密度随查询难度变化，检索类任务约 4.8%，多跳推理约 9.4%，说明误差感知预算分配有效。
- **消融结论**：最大质量增益来自残差摘要；离散度优先级和自适应预算提供额外但较小的提升；每块两个摘要可进一步改善质量，但会牺牲约 10% 加速。

## 7. 优点

- **理论支撑强**：给出可计算的分块输出误差界，并据此设计优先级，而非仅凭经验启发式。

## 8. 不足与局限

- **真实模型覆盖有限**：仅在一个模型（Llama-3.1-8B-Instruct 4-bit）上评测，未验证在不同架构、不同规模、不同预训练分布上的稳健性。
