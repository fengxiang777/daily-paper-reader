## 摘要
当前通过强化学习训练语言模型的主流范式严重依赖稀疏的结果奖励。然而，当我们追求需要更长、更复杂轨迹的任务时，这类策略会导致学习缓慢。先前工作尝试通过奖励部分进展来解决这一问题；然而，朴素的公式通常存在偏差，并会收敛到次优策略。我们证明，一种简单且无偏的密集奖励形式——我们称之为渐进点匹配——通过在片段层面奖励部分进展，在理论上和通过合成环境的实证中，都能以指数级更高的效率扩展到长时程任务。随后，我们展示了如何利用每个任务的一条参考轨迹来实际实例化渐进点匹配。在极难的数学推理问题上，稀疏结果奖励无法取得任何进展，而以成功率或 pass@k 衡量时，片段级奖励能够在更大的测试时 token 预算下带来改进。

## Abstract
Current paradigms for training language models via reinforcement learning rely heavily on sparse outcome rewards. However, as we pursue tasks that require longer and more complicated trajectories, such strategies result in slow learning. Prior work has attempted to address this problem by rewarding partial progress; however, naive formulations are often biased and converge to suboptimal policies. We show that a simple and unbiased dense reward formulation, which we term progressive point matching, scales exponentially more efficiently to long-horizon tasks by rewarding partial progress on a segment level, both theoretically and empirically via synthetic environments. We then show how progressive point matching can be practically instantiated using a single reference trajectory per task. On extremely hard math reasoning problems, sparse outcome rewards cannot make any progress, whereas segment-level rewards enable improvements at larger test-time token budgets when measured by success rate or pass@k.

## 2. 方法论：渐进点匹配（Progressive Point Matching, PPM）

- **核心思想**：将推理过程视为在状态空间中逐步到达若干“推理点”的过程。一个推理点是对后续推理而言足够充分的中间结果，例如一个已经证明的引理、一个中间计算结论等。
- **状态表示**：用当前轨迹前缀已经到达的推理点集合来表示状态；目标是使该集合包含最终答案对应的目标点。
- **参考轨迹与推理点**：对每个任务使用一条参考轨迹（oracle 解或较优解），从中提取中间推理点。
- **PPM 度量**：  
  定义 \(\phi(s, s_{\text{ref}})\) 为状态 \(s\) 中包含的参考推理点数量。  
  即：  
  \[
  \phi(s, s_{\text{ref}}) = \sum_{i=1}^{n} \mathbf{1}(s_{\text{ref},i} \in s)
  \]
  其中 \(s_{\text{ref},i}\) 是参考轨迹中的第 \(i\) 个推理点。
- **段级奖励**：  
  通过相邻片段前缀的 PPM 度量差值得到每段的奖励：  
  \[
  \hat{r}(s_t, a_t) = \phi(s_{t+1}) - \phi(s_t)
  \]
  这样，每个片段的奖励反映该片段对“覆盖更多推理点”的贡献。
- **无偏性与最优性等价**：  
  引入“shortcutting”机制：如果某推理点的后继推理点已经到达，则认为该推理点也已经到达；特别地，一旦到达最终目标，则所有推理点都视为已到达。  
  由此可以证明（Proposition 4.1）：  
  **在 PPM 奖励下最大化期望回报，与在稀疏结果奖励下最大化期望回报，具有相同的最优策略集合**。
- **与现有 RL 算法结合**：  
  该方法可作为对 GRPO 等策略梯度算法的模块化修改：
  1. 采样一条 on-policy 轨迹；
  2. 将轨迹切分为若干片段（按轮次或等长 chunk）；
  3. 对每个片段前缀计算 PPM 度量 \(m_k = \phi((c_1,\dots,c_k), x_{\text{ref}})\)；
  4. 计算段级奖励 \(r_k = m_k - m_{k-1}\)；
  5. 基于这些段级奖励计算 token 级优势，例如使用 GRPO 的组内归一化；
  6. 按 REINFORCE 目标更新策略参数。
