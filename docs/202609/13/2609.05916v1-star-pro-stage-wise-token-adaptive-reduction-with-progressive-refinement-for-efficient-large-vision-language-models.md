## 摘要
大视觉语言模型（LVLMs）实现了强大的多模态理解能力，但其处理的数百到数千个视觉token带来了大量计算开销，这推动了无需训练的视觉token剪枝方法的研究。本文对视觉token剪枝进行了两项互补分析。首先，我们测量了跨模态融合前保留token在特征空间中的覆盖范围，发现激进剪枝会丢弃大量视觉信息。其次，我们跟踪了解码器各层中文本到视觉的注意力，发现被认为重要的视觉token随层深发生显著变化，使得一次性剪枝决策不可靠。这些发现共同表明，有效的剪枝应在融合前保留广泛的视觉覆盖，并在融合过程中随着跨模态证据的演变逐步细化保留的token。因此，我们提出了STAR-Pro（分阶段自适应Token缩减与渐进式细化），一种无需训练的两阶段框架。其自适应阶段利用主元QR分解构建一个超预算的特征覆盖候选池，而渐进阶段在选定的解码器层利用不断演化的文本到视觉注意力，在目标层平均token预算下剪枝得到一个嵌套的幸存集合。在七种多架构的大视觉语言模型以及18个图像和视频基准上的大量实验证明了STAR-Pro在激进剪枝下的有效性。在LLaVA-Video-7B上，STAR-Pro将视觉token减少了90.5%，保持了基线性能的92.7%，并实现了2.24倍的实测推理加速。代码见https://github.com/EasonAI-5589/starpro。

## Abstract
Large vision-language models (LVLMs) achieve strong multimodal understanding, but the hundreds to thousands of visual tokens they process impose substantial computational overhead, motivating training-free visual token pruning. In this work, we conduct two complementary analyses of visual token pruning. First, we measure the feature-space coverage of tokens retained before cross-modal fusion and find that aggressive pruning discards substantial visual information. Second, we track text-to-visual attention across decoder layers and find that the visual tokens considered important change substantially with depth, making one-shot pruning decisions unreliable. Together, these findings show that effective pruning should preserve broad visual coverage before fusion and progressively refine the retained tokens as cross-modal evidence evolves during fusion. We therefore propose STAR-Pro (STage-Wise Adaptive Token Reduction with Progressive Refinement), a training-free two-stage framework. Its Adaptive Stage applies pivoted QR to construct an over-budget feature-coverage candidate pool, while its Progressive Stage uses evolving text-to-visual attention at selected decoder layers to prune a nested survivor set under a target layer-average token budget. Extensive experiments across seven LVLMs spanning multiple architectures and 18 image and video benchmarks demonstrate the effectiveness of STAR-Pro under aggressive pruning. On LLaVA-Video-7B, STAR-Pro reduces visual tokens by 90.5%, retains 92.7% of baseline performance, and achieves a $2.24\times$ measured inference speedup. Code is available at https://github.com/EasonAI-5589/starpro.

- **整体含义**：论文指出，有效的剪枝应当满足两个互补要求：
  1. 在跨模态融合前保留广泛的视觉特征空间覆盖；
  2. 在解码器内部随着跨模态证据的演化逐步细化保留的 token。
  
  为此，论文提出 **STAR-Pro**，一种无需训练的两阶段视觉 token 剪枝框架。

## 2. 论文提出的方法论

### 2.1 核心思想

STAR-Pro 采用“先覆盖、后细化”的两阶段策略：

- **Adaptive Stage（自适应阶段）**：在视觉 token 进入 LLM 之前，使用 pivoted QR 分解构造一个**超预算的特征覆盖候选池**（candidate pool），保留尽可能多的互补视觉方向。
- **Progressive Stage（渐进阶段）**：在选定的解码器层，利用不断演化的文本到视觉注意力，对候选池进行**嵌套式剪枝**，逐步剔除不重要的 token，最终满足给定的层平均 token 预算。

### 2.2 关键技术细节与算法流程

#### Adaptive Stage：特征覆盖候选池构建

- 设视觉侧特征表示为 \(F_v \in \mathbb{R}^{n \times d_s}\)，目标层平均预算为 \(T\)，候选池大小 \(m = \alpha T\)（\(\alpha\) 为超参数，默认 2）。
- 将 \(F_v^\top\) 的列视为 token 特征向量。候选选择目标为最大化所选子集张成的 Gram 行列式体积：

\[
S^\star = \arg\max_{\substack{S \subseteq \{1,\dots,n\}\\ |S|=m}} \det(Z_S^\top Z_S)^{1/2}
\]

- 采用贪心列主元 QR 分解近似求解：每次迭代选择与当前已选 span 正交残差最大的 token 作为下一个主元。最终得到覆盖导向的候选池 \(C\)。

#### Progressive Stage：基于演化注意力的嵌套细化

- 设候选池 \(S_0 = C\) 进入解码器。在 \(P\) 个剪枝层 \(\mathcal{L} = \{\ell_1, \dots, \ell_P\}\) 上，分别将幸存 token 数从 \(m_0\) 逐步降至 \(m_1, \dots, m_P\)，满足层平均预算约束：

\[
\frac{\ell_1 m_0 + \sum_{k=1}^P (\ell_{k+1} - \ell_k) m_k}{L} = T
\]

- 在每层 \(\ell_k\)，对当前幸存视觉 token \(v \in S_{k-1}\) 计算注意力得分：

\[
r_v^{(\ell_k)} = \frac{1}{n_q H} \sum_{j=1}^{n_q} \sum_{h=1}^H A_{j,v}^{(\ell_k), h}
\]

  即对所有文本 token 和注意力头取平均。

- 保留得分最高的 \(m_k\) 个视觉 token，形成嵌套集合 \(S_0 \supseteq S_1 \supseteq \dots \supseteq S_P\)；被移除的 token 不再重新引入。

### 2.3 架构特定配置

- 不同模型使用不同的剪枝层和预算调度，例如：
  - LLaVA-1.5-7B：\(L=32\)，剪枝层 \(l_{12}\) 和 \(l_{20}\)。
  - LLaVA-NeXT-7B：同样使用 \(l_{12}\) 和 \(l_{20}\)。
  - Qwen3-VL-8B：使用 \(l_{14}\) 和 \(l_{24}\)。
  - InternVL3-8B：因含 thumbnail 和 local crops，候选池分配采用 4:1 权重。
- 所有调度均保持层平均视觉 token 数等于目标预算 \(T\)。
