## 摘要
长时程大语言模型（LLM）智能体依赖外部记忆系统在扩展交互中保留用户偏好与任务知识。传统检索机制优化的是语义兼容性而非下游效用，常常将过时、误导或冲突的证据引入活跃上下文。我们提出 MeClear，一种任务条件化的记忆清除框架，通过合作归因识别具有负向下游效用的记忆，并在智能体执行过程中选择性地抑制这些记忆。MeClear 将留一法筛选与采样合作 Shapley 归因相结合，在相互作用的证据之间分配效用，有效解决了单次移除评估失效的冗余冲突掩盖问题。利用归因排序，MeClear 在嵌套过滤上执行查询范围的最小清除策略，在不永久改变持久记忆库的情况下验证清除后上下文中的任务恢复。在十个长对话记忆池上的综合实验评估表明，MeClear 实现了 85.9% 的目标召回率和 82.3% 的整体任务恢复率，比留一法（LOO）基线提高了 25.5 个百分点。

## Abstract
Long horizon Large Language Model (LLM) agents rely on external memory systems to preserve user preferences and task knowledge across extended interactions. Conventional retrieval mechanisms optimize semantic compatibility rather than downstream utility, frequently introducing outdated, misleading, or conflicting evidence into the active context. We present MeClear, a task conditioned memory clearance framework that identifies memories featuring negative downstream utility through cooperative attribution and selectively suppresses them from agent execution. MeClear combines Leave One Out screening with sampled cooperative Shapley attribution to distribute utility across interacting evidence, effectively resolving redundant conflict masking where single removal evaluations fail. Utilizing attribution rankings, MeClear executes a query scoped minimal clearance strategy over a nested filtration, verifying task recovery on the cleared context without permanently altering the persistent memory bank. Comprehensive experimental evaluations across ten long dialogue memory pools demonstrate that MeClear achieves a target recall of 85.9% and an overall task recovery rate of 82.3%, representing a 25.5 percentage point improvement over Leave One Out (LOO) baselines.

## 1. 论文的核心问题与整体含义

- **研究背景**：长时程 LLM 智能体依赖外部记忆系统保存用户偏好与任务知识。但是，随着交互历史增长，记忆库会积累过时、误导、冗余或相互冲突的记录。
- **核心矛盾**：传统检索机制只优化语义相似度，无法保证记忆对下游任务的实际效用。语义相关的记忆可能对当前任务有害。
- **现有方法的缺陷**：
  - 单记录删除 / 留一法（LOO）在冗余有害记忆场景下会失效：删除一条冗余有害记忆后，另一条仍然导致失败，局部效应为零，无法识别有害记忆。
  - 直接修改持久记忆库存在高风险：记录效用是查询依赖的，对某查询有害的记忆可能对后续任务不可或缺，永久覆盖会导致跨任务性能退化。
- **整体含义**：MeClear 旨在任务条件下，通过合作博弈论归因识别具有负向下游效用的记忆，并在查询范围内选择性地抑制它们，同时避免永久修改记忆库，实现安全、可逆、最小干预的记忆清除。

## 2. 方法论

MeClear 包含四个核心阶段：**任务条件上下文检索、局部反事实筛选、合作式归因、验证式查询级清除**。

- **问题形式化**：
  - 将检索到的活跃上下文 \(M_t\) 视为合作博弈，记忆记录为“玩家”，任务效用函数 \(v_t(S)\) 为特征函数。
  - 每条记忆的 Shapley 值 \(\psi_{t,i}\) 衡量其在各种上下文联盟中的平均边际贡献。负值表示记忆平均上降低任务效用。
  - 有害记忆集合定义为 \(\mathcal{H}_t = \{m_i \mid \psi_{t,i} < -\tau\}\)，其中 \(\tau\) 为容差阈值。

- **局部反事实筛选（LOO）**：
  - 对每条记忆计算局部效应 \(d_{t,i} = v_t(M_t) - v_t(M_t \setminus \{m_i\})\)。
  - LOO 提供可解释的初始筛查信号，但不作为最终有害性判据。
  - **定理 1（冗余有害盲点）**：当两条记忆互为冗余替代且均有害时，单独删除任一条的 LOO 效应为零，但二者的 Shapley 贡献均为 \(-\Delta_t/2\)。这证明 LOO 无法揭示冗余有害记忆。

- **合作式归因（采样 Shapley）**：
  - 使用 \(L\) 个随机排列估计 Shapley 值：
    \[
    \hat{\psi}_{t,i}^{(L)} = \frac{1}{L}\sum_{\ell=1}^{L} \left[ \hat{v}_t(P_i(\pi^{(\ell)}) \cup \{m_i\}) - \hat{v}_t(P_i(\pi^{(\ell)})) \right]
    \]
  - **命题 1**：该估计器无偏，并满足 Hoeffding 浓度界，给出有限样本误差保证。
  - 通过阈值 \(\tau\) 构建操作化有害集 \(\hat{\mathcal{H}}_t\)。
  - 额外估计配对交互效应 \(\hat{\omega}_{t,ij}\) 以诊断直接有害、冗余有害、联合有害等结构。

- **验证式查询级清除**：
  - 将有害记忆按估计贡献从最负到最不负排序，构造嵌套候选清除集 \(C_{t,j}\)。
  - 对每个候选集计算经验增益 \(\hat{g}_t(j) = \hat{v}_t(M_t \setminus C_{t,j}) - \hat{v}_t(M_t)\)。
  - 选择满足恢复谓词 \(\nu_t\) 且增益最大的最小基数候选。
  - **定理 2**：所选上下文保证经验非退化，若进行了非空清除则满足恢复验证，并在候选族中达到最小基数。
  - 全程使用冻结的上下文 \(M_t\)，不重新调用检索器，因此观察到的增益严格归因于记忆移除。

## 6. 主要结论与发现

- MeClear 总体目标召回率 85.9%，任务恢复率 82.3%，比 LOO 基线提高 25.5 个百分点。
- 在冗余冲突场景下，LOO 严重失效（召回 12.3%，恢复 6.3%），而 MeClear 保持 83.2% 召回和 68.4% 恢复。
- 在联合交互场景下，MeClear 实现 87.1% 召回和 91.8% 恢复。
- 合作式 Shapley 归因有效解决局部掩蔽，能够识别多种记忆交互结构（冗余、联合有害）。
- 验证式查询级清除在不修改持久记忆库的前提下实现任务恢复，并保持最小干预。
