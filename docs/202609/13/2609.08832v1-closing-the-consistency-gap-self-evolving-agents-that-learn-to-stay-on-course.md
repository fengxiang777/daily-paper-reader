## 摘要
基于大语言模型（LLM）的智能体可能平均表现准确，但在生产环境中并不可靠，这一差异虽已被观察到，但很大程度上仍未得到解决。在 AppWorld 基准上使用 GPT-4.1 的 ReAct 智能体，在相同任务重复执行五次时，仅有 53% 的任务能够五次全部成功，尽管其单次运行通过率平均为 77%。我们将这一 24 个百分点的差距称为一致性差距，并认为解决该问题是实现可信 AI 智能体部署的前提条件。我们提出一个自进化智能体框架，通过识别智能体轨迹中不稳定、低一致性的步骤，并将其转化为可在未来运行中调用的情景记忆，来缩小这一差距。其核心是一个一致性分析器，用于定位轨迹在多次执行中可能发生翻转的位置及原因；以及一个指南生成器，将诊断结果转化为针对性指南，写入记忆并注入到未来类似任务的智能体执行中。在 AppWorld 上使用 ReAct/GPT-4.1 时，我们的框架将同一任务评估中五次全部成功的任务比例提高了 16 个百分点，在相似任务泛化评估中提高了 13 个百分点。

## Abstract
Large language model (LLM)-powered agents can be accurate on average yet unreliable in production, a discrepancy that has been observed but remains largely unaddressed. When given the same task five times, a ReAct agent on the AppWorld benchmark using GPT-4.1 succeeds in all five runs only 53% of the time, even though its per-run pass rate averages 77%. We call this 24-point shortfall the consistency gap, and we argue that addressing it is a precondition for trustworthy AI agent deployment. We present a self-evolving agent framework that reduces this gap by identifying unstable, low-consistency steps in agent trajectories and converting them into episodic memory the agent can draw on in future runs. At its core is a Consistency Analyzer that pinpoints where and why a trajectory is likely to flip across executions, and a Guideline Generator that converts the diagnosis into targeted guidelines, committed to memory and injected into future agent executions on similar tasks. On AppWorld with ReAct/GPT-4.1, our framework raises the fraction of tasks that succeed in all five runs by +16 points on same-task evaluation and +13 points on similar-task generalization.

## 1. 论文的核心问题与整体含义

- **问题背景**：大语言模型（LLM）驱动的智能体在基准测试中常以“平均准确率”作为主要评估指标，但这种平均指标掩盖了重复执行时结果不一致的问题。同一任务、同一智能体、同一模型，在不同运行中可能得到不同结果。
- **一致性差距（Consistency Gap）**：论文将其形式化为 `Gap@k = Mean@k − Pass^k`，其中 `Mean@k` 是平均通过率，`Pass^k` 是 k 次运行全部成功的任务比例。  
  例如，在 AppWorld 基准上，ReAct/GPT-4.1 的 `Mean@5 = 77%`，但 `Pass^5` 只有 **53%**，二者相差 **24.4 个百分点**。也就是说，平均看有 77% 的任务每次能通过，但只有 53% 的任务能够在五次运行中全部通过。
- **核心含义**：平均准确率会高估智能体在真实生产环境中的可靠性。对于需要稳定、可重复行为的部署场景，这种“平均准确但不可重复”的差距是可信 AI 智能体落地的重要障碍。论文主张将一致性作为与准确性并列的一等目标，并专门设计机制来缩小该差距。

## 2. 方法论

论文提出一个**自进化智能体框架**，核心是一个离线两阶段管道：**Detect（检测）** 和 **Generate（生成）**，并在已有轨迹记忆框架 Fang et al. (2026) 的基础上，增加一致性导向的指南提取信号。

### 2.1 一致性分析器（Consistency Analyzer）

- **黑盒原则**：不需要访问模型内部 logits、激活值或智能体源代码，只通过重新调用同一个 LLM 端点来估计响应分布。
- **重采样估计步骤一致性**：对轨迹中每个推理步骤 `s_i`，将记录下的提示重新发送给同一模型 `N` 次（默认 `N=30`，温度 ≤ 0.5），得到响应集合 `D_i`。
- **步骤一致性分数 `C(s_i) ∈ [0,1]`** 根据响应类型采用不同度量：
  - **自由文本/代码响应**：使用 SBERT 嵌入的 **平均成对余弦相似度**。
  - **分类响应**（如工具名、枚举参数）：使用 **平均成对 Jaccard 相似度**。
  - **结构化响应**（如含 `thoughts`、`action`、`action_input` 字段的 JSON）：拆分为字段，对每个字段按类型计算相似度，再做 **加权求和**。
- **轨迹一致性聚合**：使用 `C_mean(T) = (1/n) Σ_i C(s_i)` 作为轨迹级分数，用作后续指南生成和结果预测的辅助信号。
- **关键思想**：单次响应的置信度无法反映决策的“抗翻转能力”；需要估计响应分布的形状。平坦分布意味着多个接近并列的 token，容易因平台噪声而翻转。

### 2.2 指南生成器（Guideline Generator）

- **标记不稳定步骤**：当某步骤一致性 `C(s_i)` 低于阈值 `θ_C = 0.85` 且该步骤位于智能体决策路径上时，将其标记为易翻转步骤。
- **生成一致性指南**：将轨迹及其得分卡（标注不稳定步骤）输入 LLM，生成三类指南：
  - **strategy**：巩固那些虽然变动大但最终正确的模式；
  - **recovery**：绕开与失败相关的高变动步骤；
  - **optimization**：跳过或简化不必要的高变动步骤。
- **记忆与检索**：生成的指南进入双索引情景记忆（嵌入索引 + 类别/优先级/上下文/来源等元数据），运行时通过**余弦相似度**或 **LLM 引导查询**进行检索，注入到后续相似任务提示中。
- **自进化循环**：操作循环执行用户任务并记录轨迹；离线分析循环将轨迹转化为指南并存入记忆；新指南在下一次运行时被检索使用，逐步减少不一致任务数量。

### 2.3 关键公式

- 一致性差距：`Gap@k(T) = Mean@k(T) − Pass^k(T)`
- 归一化一致性：`Consistency@k(T) = Pass^k(T) / Mean@k(T)`，取值 `[0,1]`。
- 步骤一致性（自由文本）：  
  `C(s_i) = (2 / (N(N−1))) * Σ_{j<k} cos(e(r_i^{(j)}), e(r_i^{(k)}))`
- 步骤一致性（分类值）：  
  `C(s_i) = (2 / (N(N−1))) * Σ_{j<k} J(r_i^{(j)}, r_i^{(k)})`
- 步骤一致性（结构化）：  
  `C(s_i) = Σ_{f∈F_i} δ_f · sim_f(D_i^f)`，且 `Σ δ_f = 1`。

  - ReAct 智能体；

- **评估指标**：
  - `Pass@k`：k 次中至少成功一次；

- **评估模式**：

  3. **轨迹一致性作为结果预测**：在 50 个 AppWorld test challenge 任务上，计算聚合轨迹一致性与真实通过/失败标签之间的 AUROC，验证其作为二元分类器的能力。

## 6. 主要结论与发现

- **一致性差距显著且普适**：GPT-4.1 的 `Gap@5` 为 24.4 pp，GPT-OSS-120B 为 23.8 pp。差距并非个别现象，且按难度分布不同：GPT-4.1 的绝对差距随难度增大而增大（easy 17.5 pp → hard 30.2 pp）；GPT-OSS-120B 因 hard 任务平均通过率过低（9.5%），绝对差距反而在 hard 上变小。
- **归一化一致性揭示能力差异**：GPT-4.1 聚合一致性为 0.69，hard 任务降至 0.51；GPT-OSS-120B 聚合一致性仅 **0.30**，hard 任务为 **0.00**，说明其成功几乎不可复现。
- **一致性指南能有效缩小差距**：
  - GPT-4.1：同任务 `Pass^5` 从 53.0% 提升到 69.0%（**+16.0 pp**），相似任务提升到 66.0%（**+13.0 pp**）；`Mean@5` 没有下降，甚至小幅上升（同任务 +3.6 pp）。
  - GPT-OSS-120B：同任务 `Pass^5` 从 10.1% 提升到 16.1%（**+6.0 pp**），相似任务提升到 18.8%（**+8.7 pp**）；`Mean@5` 同任务 +4.8 pp，相似任务 +6.6 pp。
  - 对 GPT-4.1，一致性与平均准确率可同时改善；对低能力模型，提升受限于原始能力，但仍能提取可用改进空间。
- **轨迹一致性可预测结果**：聚合轨迹一致性对通过/失败分类的 AUROC 为 **0.699**，可作为无 ground-truth 情况下指南生成器判断的辅助信号。
- **一致性不等于准确性**：高平均通过率可与低一致通过率共存；需要专门的指标、检测和优化机制来改善重复运行可靠性。

## 7. 优点

- **黑盒、模型无关、架构无关**：一致性分析器仅需重新调用 LLM 端点，无需访问内部参数或智能体代码，适用于任何基于托管 LLM 的智能体。
- **离线、非侵入式**：指南生成与重采样完全在离线阶段进行，不改变推理循环，不干预运行时；提示级注入易于集成。
- **目标明确**：将一致性作为独立于准确性的第一等目标，提出了形式化指标（`Pass^k`、Gap、归一化一致性），并针对性设计优化机制。
- **兼顾稳定性与准确性**：

同时提升 `Pass^k` 与 `Mean@k` 说明指南并非通过保守化策略牺牲正确率，而是强化了那些“暂时正确但不稳定”的执行路径，使智能体既更准又更稳。
- **可解释的自然语言指南**：生成的指南以自然语言形式存储和注入，便于开发者审计、编辑与版本管理，相比隐式权重更新或黑盒投票机制更具透明性。
- **增量式自进化闭环**：无需重新训练或替换模型，仅通过“执行—分析—生成指南—检索复用”的离线循环即可持续累积改进，适合长期部署的智能体系统。

## 8. 缺点与局限性

- **重采样成本较高**：默认 `N=30` 的重采样使每步推理 token 成本放大约 30 倍，难以直接用于实时在线场景；虽然作者提出自适应重采样方向，但未给出具体实现或成本收益分析。
- **缺乏与现有方法的直接对比**：仅与无指南基线比较，未将所提方法与自一致性投票、多数投票、语义熵、CUGA 等一致性增强方法置于相同基准下对照，限制了其相对优势的证明。
- **关键超参数未消融**：一致性阈值 `θ_C=0.85`、重采样次数 `N=30`、字段权重 `δ_f`、检索方式（余弦 vs LLM 引导）等均未做系统性敏感性分析，结果对这些选择的稳健性未知。
- **评估场景较为单一**：只在 AppWorld 的 `test normal` 划分上验证，任务类型集中于工具调用与 API 交互，向开放域对话、多智能体协作或具身智能体等场景的迁移性尚待检验。
- **同任务指南存在过拟合风险**：从单一任务轨迹生成指南并注入同一任务，可能捕捉到任务特定捷径或非稳定策略，导致对相似任务泛化时提升有限，甚至引入偏置。
- **一致性估计本身存在噪声**：重采样受限于 `N=30` 的有限样本，对低概率翻转事件的捕捉能力不足；SBERT 余弦相似度对语义等价但表达差异较大的响应可能给出偏低一致性分数。
- **平台非确定性不可控**：作者承认无法完全控制云端模型服务端的调度、硬件差异等非确定性来源，这可能混淆模型自身一致性与平台噪声的边界。

## 9. 可能的应用与启示

- **部署前可靠性审计**：将 `Consistency@k` 与 `Gap@k` 纳入 CI/CD 流程，对即将上线的智能体进行重复运行压力测试，识别高风险任务。
- **风险分级与调度**：对低一致性任务启用更保守的执行策略或人工审核，高一致性任务自动放行，从而在吞吐量与可靠性之间取得平衡。
- **提示工程与示例选择**：利用一致性分析器标记出的易翻转步骤，反向指导少样本示例的挑选与提示改写，减少决策边界附近的模糊响应。
- **与其他一致性方法互补**：本方法不改变推理时采样策略，可与自一致性投票、多数表决等运行时方法叠加，形成“离线指南 + 在线聚合”的多层一致性保障。
- **统一评估指标**：推动智能体评测社区将 `Pass^k` 或 `Consistency@k` 作为与 `Mean@k` 并列的标准指标，避免仅用平均准确率掩盖不可复现问题。

## 10. 总体评价

论文提出了一个清晰且易于落地的自进化一致性增强框架，通过黑盒重采样估计步骤一致性并生成可复用指南，在不修改模型或推理循环的前提下显著缩小了平均准确率与稳定成功之间的差距。其形式化指标 `Gap@k` 和 `Consistency@k` 对智能体可靠性评估具有较好的启发性。然而，实验验证仍处于早期阶段：场景单一、基线薄弱、缺少消融，且重采样成本较高，这些问题限制了结论的普适性与方法的直接工业部署价值。未来工作若能在多基准、多智能体架构下补充对比与消融实验，并引入自适应重采样以降低成本，将更具说服力。
