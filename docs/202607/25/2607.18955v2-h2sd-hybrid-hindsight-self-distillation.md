## 摘要
带可验证奖励的强化学习（RLVR）为语言模型推理提供可靠的结果监督，但标量轨迹奖励提供的逐token指导有限。现有的自我蒸馏方法引入了特权教师，但通常赋予其固定角色：直接分布匹配可能破坏成功行为，而仅基于幅度的调制在失败后几乎不提供纠正性指导。我们观察到，成功和失败的轨迹需要不同形式的事后监督。成功的响应已包含学生生成的有效推理路径，因此可以作为特权上下文，而不是被外部推理所取代。然而，失败的响应需要纠正性参考信息。我们引入了混合事后自我蒸馏（H$^2$SD），它根据轨迹的正确性自适应地调整教师上下文和更新策略。对于成功的轨迹，我们根据已验证的响应和改写指令构建教师上下文，并仅使用教师重新评估原始响应token。这强调了必要的推理而非冗余内容，并在不改变奖励方向的情况下细化基于幅度的信用分配。对于失败的轨迹，经验证器确认的参考提示通过反向KL蒸馏提供纠正性指导。对照消融实验表明，性能增益取决于结果条件路由和改写指令。在具有挑战性的推理基准测试上的实验表明，H$^2$SD在代表性的RLVR和自我蒸馏基线中取得了最强的整体性能，优化稳定，且在准确度和效率之间取得了有利的权衡。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) provides reliable outcome supervision for language model reasoning, but a scalar trajectory reward offers limited token-level guidance. Existing self-distillation methods add a privileged teacher but typically assign it a fixed role: direct distribution matching may destabilize successful behavior, while magnitude-only modulation offers little corrective guidance after failure. We observe that successful and failed trajectories require different forms of hindsight supervision. A successful response already contains a valid student-generated reasoning path and can therefore serve as privileged context rather than being replaced by an external rationale. A failed response, however, requires corrective reference information. We introduce Hybrid Hindsight Self-Distillation ($\mathrm{H}^{2}\mathrm{SD}$), which jointly adapts teacher context and update strategy to trajectory correctness. For successful trajectories, we construct the teacher context from the verified response and a rephrasing instruction, and use the teacher only to re-evaluate the original response tokens. This emphasizes essential deductions over redundant content and refines magnitude-based credit assignment without changing the reward direction. For failed trajectories, a verifier-confirmed reference hint provides corrective guidance through reverse-KL distillation. Controlled ablations show that the gains depend on outcome-conditioned routing and the rephrasing instruction. Experiments on challenging reasoning benchmarks show that H$^2$SD achieves the strongest overall performance among representative RLVR and self-distillation baselines, with stable optimization and a favorable accuracy-efficiency trade-off.

### 1. 论文的核心问题与整体含义

-   **研究背景**：当前，利用可验证奖励的强化学习（RLVR，如GRPO）是提升大语言模型推理能力的主流范式。其核心机制是使用一个标量（单一数值）结果奖励来优化模型。
-   **核心问题**：这种标量奖励提供的**逐token（词元）级别指导非常有限**。因为无论一个推理步骤有多关键或无关，整个响应序列都会接收到同样的奖励或惩罚信号，导致信用分配（Credit Assignment）困难。
-   **现有方法的不足与本文动机**：为解决此问题，**在线策略自我蒸馏（On-Policy Self-Distillation, OPSD）**让模型同时扮演学生和教师，教师通过接触特权信息（如正确答案）来提供细粒度监督。但现有方法存在一个关键缺陷：它们为教师**分配了固定的角色**，无法区分对待。
    -   **直接分布匹配（如OPSD）**：试图让学生完全模仿教师，但这可能会破坏模型已经生成成功的推理路径。
    -   **仅做幅度调制（如RLSD）**：只用教师信号调整更新步长，不改变方向。这在响应失败时，无法提供明确的、指明“应该怎么做”的纠正信号。
-   **整体含义**：本文的核心思想是，**成功和失败的轨迹需要截然不同的事后监督形式**。一个成功的回答本身已包含有效推理，不应被外部知识粗暴替换；而一个失败的回答则需要明确的纠正性指导。

### 2. 论文提出的方法论

-   **核心思想**：提出 **混合事后自我蒸馏（H²SD）**，一个根据轨迹**正确性进行动态路由**的框架。它分别为成功和失败的采样轨迹分配了不同的教师上下文和更新目标，实现了优势互补。
-   **关键技术细节**：
    -   **特权信息（Hint）设计**：不直接使用最终答案，而是引入一个外部更强的语言模型（在本文中是Kimi-K2.6）为每个问题生成一个包含关键中间推理步骤和最终答案的**自然语言提示（Hint）**。该提示仅在训练时作为特权信息提供给教师模型，不直接在推理时使用。
    -   **结果条件路由（Outcome-Conditioned Routing）**：根据采样轨迹是否通过规则验证器（`R(x,y) == 1`）来决定其路由。
    -   **成功路径：精细化信用分配（Magnitude-Only Modulation）**：
        -   **教师上下文**：将已验证为正确的学生响应，连同一条“改写”指令一起交给教师模型。
        -   **目标**：教师模型基于这个改写后的、已验证为正确的上下文，重新评估原始响应中每个token的对数概率。
        -   **作用**：通过RLSD的幅度调制机制，在不改变奖励函数确定的优化方向（正奖励）的前提下，**上调关键推理token的更新权重，下调冗余token的权重**，从而实现精细化的奖励分配。这相当于强调学生有效推理中的精华部分。
    -   **失败路径：分布层面纠正（Reverse-KL Distillation）**：
        -   **教师上下文**：教师模型会接收到外部生成的**参考提示（Hint）**。
        -   **目标**：计算学生分布 `p_S` 到教师分布 `p_T` 的**反向KL散度（`KL(p_S || p_T)`）**，并将其最小化。
        -   **作用**：这为学生提供了一个明确的“追赶”目标，**直接引导学生策略向提示中包含的正确推理分布靠拢**，从而提供直接的纠正性指导，而不仅仅是惩罚当前错误的token。
    -   **最终目标函数**： `ℒ_H²SD = E[ ℐ_success · ℒ_RLSD + γ · ℐ_fail · ℒ_RKL ]`，其中 `ℐ` 是指示函数，`γ` 控制失败轨迹纠正的强度。

### 6. 论文的主要结论与发现

-   **性能最优**：H²SD在所有评估方法中取得了**最强的综合性能**，尤其在Sudoku任务上提升巨大（例如，6×6数独准确率从基线的35.25%提升至76.50%），并在未见过的迷宫尺寸上展现出良好的泛化能力。
-   **路由策略至关重要**：颠倒路由（即对成功轨迹用反向KL，对失败轨迹用幅度调制）会导致性能崩溃和探索熵的急剧下降，这证明了“成功激励，失败纠正”这一设计原则的正确性。
-   **过程级特权信息价值高**：与仅提供最终答案相比，包含中间推理步骤的**过程级提示（Hint）**能带来更显著的性能提升。
-   **改写指令的作用**：对成功轨迹进行改写，能够在不损害策略多样性的前提下，帮助模型去粗取精，提升token级信用分配的质量，从而实现更好的准确率-效率权衡。
-   **效率优势**：H²SD在取得最高准确率的同时，通常能产生**更短的平均响应长度**，表明其性能增益并非源自更长的推理链，而是更高效的推理过程。

### 7. 优点

-   **新颖的混合框架**：首次明确区分并针对性地处理成功与失败轨迹，巧妙地将幅度调制和分布匹配的优势结合起来。
-   **设计精妙且有效**：对成功轨迹使用“改写”作为教师上下文，是既保留学生有效推理又可提炼关键步骤的优雅设计，避免了生硬的外部知识注入。
-   **实验严谨扎实**：通过大量且公平的消融实验，清晰地验证了结果条件路由、改写指令和过程级特权信息等各个组件的独立贡献，因果关系明确。
-   **性能与效率兼得**：不仅提升了模型的推理准确率，还缩短了冗余推理的长度，展现了优越的准确率-效率权衡。

### 8. 不足与局限

-   **依赖外部强模型**：H²SD依赖于一个外部更强的模型（Kimi-K2.6）来生成参考提示，这引入了额外的预处理成本和前置依赖。对于该强模型无法解决的问题，该方法可能失效。
-   **单一模型规模评估**：所有实验仅在Qwen3-30B-A3B这一中等规模的模型上进行。论文坦承，更小模型因初始成功率过低（冷启动问题）难以应用此方法，其在不同规模、尤其是更大模型上的效果和扩展性有待验证。
-   **任务类型相对集中**：验证场景全部为具有明确、可编程验证器（如规则检查）的逻辑推理任务。其在更开放、奖励信号更模糊（如创意写作、开放域对话）的任务上的适用性有待探索。
