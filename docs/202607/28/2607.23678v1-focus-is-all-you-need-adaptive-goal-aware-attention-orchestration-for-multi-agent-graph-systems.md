## 摘要
大型语言模型（LLMs）使自主智能体能够进行推理、规划和工具调用。近期系统越来越多地将这些智能体组织为由专门化、相互连接的节点构成的图。尽管基于图的编排支持灵活的分解与协调，但这也带来了一个关键挑战：注意力分配。随着工作流的增长，现有方法往往均匀地执行图构件，在无关或低影响的任务上浪费资源。我们提出了注意力编排，这是一种将Transformer风格的注意力从令牌表征扩展到工作流级智能体协作的范式。我们的框架——自适应目标感知注意力编排（AGAO）——根据用户目标、图依赖关系和计算约束，动态评估智能体的重要性。AGAO结合了三个组件：（1）目标感知注意力，衡量用户目标与智能体能力之间的语义相关性；（2）拓扑感知注意力，建模智能体图中的结构依赖关系；（3）资源感知注意力，在异构智能体之间分配预算和执行优先级。这些机制共同将静态智能体图转换为自适应系统，将计算聚焦于目标关键推理路径。在多种多智能体工作负载上的实验表明，与现有的基于图的执行策略相比，AGAO提高了任务效果，同时减少了不必要的计算、延迟和令牌消耗。我们的工作确立了注意力工程作为可扩展、智能的多智能体系统的一个方向。代码：https://github.com/MingzhouFan97/AGAO。

## Abstract
Large language models (LLMs) enable autonomous agents for reasoning, planning, and tool use. Recent systems increasingly organize these agents as graphs of specialized, interconnected nodes. Although graph-based orchestration supports flexible decomposition and coordination, it creates a key challenge: \textbf{attention allocation}. As workflows grow, existing approaches often execute graph components uniformly, wasting resources on irrelevant or low-impact tasks. We introduce \textbf{Attention Orchestration}, a paradigm that extends Transformer-style attention from token representations to workflow-level agent coordination. Our framework, \textbf{Adaptive Goal-aware Attention Orchestration (AGAO)}, dynamically estimates agent importance based on user objectives, graph dependencies, and computational constraints. AGAO combines three components: (1) goal-aware attention, measuring semantic relevance between user goals and agent capabilities; (2) topology-aware attention, modeling structural dependencies in agent graphs; and (3) resource-aware attention, allocating budgets and execution priorities across heterogeneous agents. Together, these mechanisms transform static agent graphs into adaptive systems that focus computation on goal-critical reasoning paths. Experiments across diverse multi-agent workloads show that AGAO improves task effectiveness while reducing unnecessary computation, latency, and token consumption compared with existing graph-based execution strategies. Our work establishes \textbf{Attention Engineering} as a direction for scalable, intelligent multi-agent systems. Code: https://github.com/MingzhouFan97/AGAO.

## 1. 论文的核心问题与整体含义
- **研究背景**：多智能体系统正从单智能体循环（Loop Engineering）向基于图的多智能体工作流（Graph Engineering）演进。图结构能清晰表达任务分解、依赖与并行，极大提升了复杂任务的协调能力。
- **核心问题**：随着图规模扩大，现有系统往往均匀执行图中所有可达节点，导致 **注意力稀释** ——大量计算资源被分配给与当前目标无关或低影响力的任务，造成推理质量下降、延迟和 token 消耗急剧增加。
- **整体含义**：论文提出 **注意力工程（Attention Engineering）** 这一新范式，将 Transformer 中的注意力从令牌级表征学习延伸至工作流层级的编排。核心观点是：未来智能体系统不仅需要“知道有什么任务以及它们如何连接”，更需要“知道哪些任务在当下值得关注”。

## 2. 论文提出的方法论
论文提出 **自适应目标感知注意力编排（AGAO）** 框架，在用户目标与智能体图执行之间插入一个动态注意力层。其核心由三个互补的注意力机制构成：

### 2.1 目标感知注意力
- 编码用户目标为查询向量 \(Q_g\)，编码每个智能体的能力描述、历史执行状态为键 \(K_i\) 和值 \(V_i\)。
- 通过放缩点积计算语义相关性分数 \(e_i = \frac{Q_g K_i^T}{\sqrt{d}}\)，经 softmax 归一化得到注意力权重 \(\alpha_i^{\text{goal}}\)。
- 该权重衡量智能体对当前目标的语义贡献度，使执行优先聚焦于高相关智能体。

### 2.2 拓扑感知注意力
- 将图结构信息（依赖距离、前驱/后继影响、关键路径中心度等）转换为拓扑偏置矩阵 \(B_G\)。
- 在注意力计算中显式加入图偏置：\(A_{topo} = \text{softmax}(\frac{QK^T}{\sqrt{d}} + B_G)\)。
- 同时计算全局结构影响力分数 \(s_i^{\text{critical}}\)，并由超参数 \(\gamma\) 融合语义注意力与拓扑注意力：\(\alpha_i^{\text{graph}} = \gamma \alpha_i^{\text{goal}} + (1-\gamma)\alpha_i^{\text{topo}}\)。
- 作用：避免纯语义剪枝，保留结构中不可或缺的中间节点。

### 2.3 资源感知注意力
- 将融合后的注意力分数 \(\alpha_i^*\) 转化为具体执行策略：
  - **模型路由**：高注意力节点分配强推理模型 (M_large)，低注意力节点分配小模型。
  - **令牌预算分配**：按注意力分数 softmax 比例动态分配总 tokens。
  - **执行优先级调度**：结合注意力与紧急度 \(\alpha_i^* \cdot w_i\) 排序。
- 整体在计算预算 \(B\) 约束下最大化加权效用。

### 2.4 自适应图路由与执行算法
- 执行过程中，根据中间观察结果 \(o_t\) 更新注意力状态 \(\alpha^{t+1} = \Phi(\alpha^t, o_t, G, q)\)，包含反馈注意力 \(\alpha^{\text{feedback}}\)。
- 根据更新后的 \(\alpha\) 对节点进行激活/挂起/剪枝决策，实现动态路径聚焦。
- 整体流程如 Algorithm 1 所示，循环执行“计算注意力→分配资源→执行→观察反馈→更新状态”。

## 3. 实验设计
- **数据集与场景**：在 **16 个任务** 上进行评测，包括 **8 个 MBPP 编程任务** 与 **8 个 HotpotQA 多跳问答任务**。
- **图设定**：每个任务使用人工指定的 **9 节点图**（编程图含规范分析、实现、测试等角色；问答图含问题分解、检索、证据筛选、推理等角色）。
- **对比基准**：五种执行策略。
  - Random：依赖合法条件下随机选 ≤2 个就绪节点。
  - Static：按固定图顺序执行所有依赖合法节点。
  - Semantic：基于任务提示与节点能力描述的词汇重叠选择节点。
  - MoE-style：固定混合词汇相关性及拓扑分数的选择，无反馈、无自适应资源路由。
  - AGAO (Ours)：融合目标相关性、拓扑分数和规则化反馈；可跳过低分节点，并按注意力度选择低/中/高能力模型。
- **评估指标**：MBPP 采用 pass@1（断言通过率）；HotpotQA 采用 token 级 F1；同时记录活跃节点数、累计智能体执行时间（sum of node times）、网关报告的输入/输出 token 量。每个策略每项任务仅运行一次，结果为描述性初步均值。

## 6. 论文的主要结论与发现
- **性能**：AGAO 在 MBPP 上 pass@1 达 0.875，优于所有基线（最佳基线 MoE 为 0.75）；在 HotpotQA 上 F1 为 0.340，低于 MoE 的 0.417，但高于 Static (0.319)、Random (0.285)、Semantic (0.244)。表明效果随工作负载有所差异。
- **效率**：AGAO 激活的节点数最少，累积代理时间相比 Static 降低约 56% (MBPP) 和 50% (HotpotQA)，节省显著。
- **成本**：AGAO 输入 token 增加，但输出 token 大幅减少。因输出 token 单价更高，整体 API 成本更为经济。
- **消融**：完整 AGAO 在编码准确率、QA 质量与执行效率三者间达到最均衡。去除任一组件都会在某个指标上出现明显退化。
- **范式启示**：多智能体图系统需要“图结构+注意力”的智能组合，注意力工程是下一阶段自主智能体系统的新抽象层。

## 7. 优点
- **范式创新**：首次将“注意力编排”提升为系统级设计原则，清晰区分了 Loop Engineering、Graph Engineering、Attention Engineering 三代演进。
- **多维度注意力融合**：同时考虑语义（目标）、结构（拓扑）和资源三维信息，相较单纯语义或固定路由更接近实际系统需求。
- **动态自适应**：支持基于执行反馈的注意力更新，使系统能在运行时调整聚焦点，而非一次性静态规划。
- **效率与质量平衡**：在多个任务上以更少节点、更低时耗达到甚至超越全量执行的效果，实用价值高。
- **经济考量**：显式建模输出 token 高成本现实，通过调整模型选择与预算分配进行成本优化。

## 8. 不足与局限
