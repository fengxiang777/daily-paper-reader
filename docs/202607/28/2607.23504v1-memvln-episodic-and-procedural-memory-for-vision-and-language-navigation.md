## 摘要
连续环境中的视觉与语言导航（VLN-CE）要求智能体在低延迟执行动作的同时，保持长时域视觉历史以确保轨迹一致性。现有的基于视频的VLN方法通常难以同时满足这两项需求。为应对这些挑战，我们提出MemVLN，一个新颖的VLN框架，以实时推断效率（14 FPS）实现先进性能。MemVLN利用视觉编码器处理连续观测，并使用大语言模型（LLM）解读指令并生成动作。我们方法的核心是采用金字塔分辨率的情景记忆管理。该机制将计算集中处理当前感知，同时保留压缩的长期历史。作为补充，我们引入程序性记忆以实现快速动作，通过一个紧凑的原子中层动作词汇表来绕过自回归解码延迟。在VLN-CE上的实验显示，MemVLN-4B在R2R中相较于基线Qwen3-VL-4B架构成功率（SR）提升5.8%，在RxR中提升9.7%，同时推断延迟实现7倍加速。

## Abstract
Vision-and-Language Navigation in Continuous Environments (VLN-CE) requires agents to maintain long-horizon visual history for trajectory consistency while executing actions with low latency. Existing video-based VLN approaches typically struggle to satisfy both demands simultaneously. To address these challenges, we propose MemVLN, a novel VLN framework that achieves state-of-the-art performance with real-time inference efficiency (14 FPS). MemVLN utilizes a visual encoder to process continuous observations and a Large Language Model (LLM) to interpret instructions and generate actions. Central to our approach is an Episodic Memory management that applies pyramidal resolutions. This mechanism concentrates computation on immediate percepts while retaining compressed long-term history. Complementing to this design, we introduce Procedural Memory for fast action with a compact vocabulary of atomic mid-level actions to bypass auto-regressive decoding latency. Experiments on VLN-CE show that MemVLN-4B surpasses the baseline Qwen3-VL-4B architecture by 5.8\% SR in R2R and 9.7\% SR in RxR, while achieving a 7$\times$ speedup in inference latency.

## 2. 方法论

### 2.1 核心思想
- 仿照人类记忆机制，分别设计**情景记忆**（Episodic Memory）用于管理视觉观测历史，**程序性记忆**（Procedural Memory）用于快速生成动作。

### 2.2 关键技术细节

- **情景记忆：金字塔分辨率策略**
  - 将历史帧按时间远近分为三个层级：即时层（immediate）、短期层（short‑term）、长期层（long‑term），分辨逐级降低。
  - 近期观测保持较高分辨率（如 512×512），远期观测用更小分辨率（如 128×128），远期序列累计 token 数不超过一张即时帧的 token 总量，从而在不增加总 token 预算的前提下扩展有效回溯窗口。
  - 相对于 Token Merging 等潜在空间压缩方式，金字塔分辨率在原始像素空间操作，保持均匀 2D 空间网格，可兼容 M‑RoPE、DeepStack 等现代设计。

- **程序性记忆：快速动作机制**
  - 将导航动作映射到一个紧凑的“原子中层动作”词表（如 `move_forward` 分段距离、`turn_left` 角度等），将这些中层动作重新赋予 LLM 词表中的单个 token。
  - 模型在单次前向传播中直接输出一个动作 token，避免自回归逐 token 解码带来的延迟，实现 14 FPS 的实时推断。

- **公式要点**：对于时刻 $t$ 的历史帧 $v_t$，分辨率调整依赖其时间距离 $T$：
  $$
  v'_t = \begin{cases}
  \text{Rescale}(v_t, r_\text{imm}), & T-B_\text{short} < t \le T-1 \\
  \text{Rescale}(v_t, r_\text{short}), & T-B_\text{long} < t \le T-B_\text{short} \\
  \text{Rescale}(v_t, r_\text{long}), & 0 \le t \le T-B_\text{long}
  \end{cases}
  $$
  训练目标为最大化单步原子动作 $a_t^*$ 的似然：
  $$
  \mathcal{L} = -\frac{1}{T}\sum_{t=1}^T \log P(a_t^* \mid F_t, I; \theta)
  $$

### 2.3 模型架构概览
- 视觉编码器 $E_\text{vis}$ 处理金字塔分辨率筛选后的帧集 $S_t$，得到视觉特征 $F_t$。
- 特征与语言指令 $I$ 一并送入大语言模型，进行跨模态决策。
- 最终从扩充的动作词表中单次解码出动作 $a_t$。
