## 摘要
全模态大语言模型（OmniLLMs）正迅速将多模态推理扩展至同步音视频领域。然而，由此产生的音视频令牌序列较长，导致推理时预填充延迟高、GPU内存占用大。现有的令牌剪枝方法主要针对纯视觉输入设计，既未考虑音频与视频之间的跨模态关联，也忽略了决定内容重要性的用户查询。为了弥补这一不足，我们提出了Omni-Prune，一种无需训练、查询感知的音视频令牌剪枝框架，能够联合去除两种模态中的冗余，同时保留与任务相关的跨模态证据。具体而言，Omni-Prune首先将令牌序列分割为自适应时间窗口，这些窗口位于音频显著峰值处；然后在单一尺度上对音频和视频令牌进行评分，该评分结合了编码器注意力与文本查询相关性；并将相关的音视频令牌配对，以便一起保留。在每个窗口内，最后的K-medoids步骤选出少数代表性令牌，补充了仅靠基于评分的筛选所遗漏的多样性线索。大量实验表明，Omni-Prune优于现有基线方法，实现高达3.25倍的预填充加速和1.3倍的内存减少，同时保持超过99%的全模型性能。

## Abstract
Omnimodal large language models (OmniLLMs) are rapidly extending multimodal reasoning to cover synchronized audio and video. However, the resulting audio-video token sequences are long, leading to high prefill latency and GPU memory usage at inference time. Existing token pruning methods, designed mainly for vision-only inputs, miss both the cross-modal links between audio and video and the user query that decides which content matters. To bridge this gap, we present Omni-Prune, a training-free, query-aware audio-visual token pruning framework that jointly removes redundancy from both modalities while keeping task-relevant cross-modal evidence. Specifically, Omni-Prune first splits the token sequence into adaptive time windows placed at audio saliency peaks, then scores audio and video tokens on a single scale that combines encoder attention with text-query relevance, and pairs related audio-video tokens so that they are kept together. Within each window, a final K-medoids step then selects a few representative tokens, adding diverse cues that score-based selection alone would miss. Extensive experiments demonstrate that Omni-Prune outperforms established baseline methods, delivering up to 3.25x prefill speedup and 1.3x memory reduction while retaining over 99% of full-model performance.

- **研究背景**：全模态大语言模型（OmniLLMs）能够联合处理文本、音频和视频，实现细粒度的视听推理。然而，同步音视频输入会产生极长的令牌序列（例如，一分钟视频可产生约 \(10^4\) 个令牌），导致推理时自注意力计算成本高昂，产生高预填充延迟和GPU内存瓶颈。
- **核心问题**：现有的令牌剪枝方法主要针对纯视觉模型设计，存在两个关键缺陷：
    1.  忽略了音频与视频流之间在时间上对齐、语义上互补的跨模态关联。
    2.  剪枝决策过程与下游任务的核心（即用户查询）脱节，无法判断哪些内容对回答问题是必要的。
- **整体含义**：提出一种 无需训练、查询感知 的音频-视频令牌统一剪枝框架，在显著降低计算开销的同时，精确保留与用户意图相关的跨模态证据，实现近乎无损的推理加速。

### 2. 方法论

Omni-Prune框架包含三个核心阶段，其工作流程如下：

- **阶段一：音频锚点自适应窗口划分**
    - **核心思想**：观察到音频显著事件（如语音起止、特效）常与重要视频瞬间共现，因此以音频注意力峰值作为自然的内容分割边界。
    - **实现方式**：将音频令牌序列按时间与视频帧对齐，计算每段音频的平均编码器注意力分数作为显著度。通过峰值检测识别显著点，并设置最小窗口间隔 \(f_{min}\) 来抑制噪声，形成内容感知的自适应时间窗口。

- **阶段二：跨模态关系图谱与令牌评分**
    - **统一的重要性评分**：在每个窗口内，对音频和视频令牌进行统一评分。
        - **编码器注意力分 \(v_i\)**：从编码器最后一层自注意力中提取，并对窗口内所有音视频令牌进行联合最小-最大归一化。
        - **文本查询相关性分 \(r^{\text{text}}_i\)**：计算每个多模态令牌与用户查询文本令牌的余弦相似度，并归一化到 \([0, 1]\)。
        - **综合评分 \(\phi_i = v_i + r^{\text{text}}_i\)**：融合模态内部显著性和任务导向的语义相关性。最终根据综合评分，在每个窗口内预选出高置信度的保留候选集。
    - **跨模态耦合**：构建窗口内音视频令牌的余弦相似度矩阵。对于未在预选中保留的令牌，通过双向贪婪匹配算法，找出语义上最相关的音视频令牌对。若配对分数超过阈值 \(\gamma\)，则将其成对保留，以维护跨模态信息的连贯性。

- **阶段三：多样性保持的聚类**
    - **核心思想**：弥补前两阶段仅根据重要性筛选所导致的表征多样性损失，恢复那些虽得分不高但可能提供背景等互补信息的“长尾”令牌。
    - **实现方式**：对每个窗口内每种模态的未选中令牌，独立应用 K-medoids 聚类。按比例 \(\rho_c\) 选取聚类中心（medoids）作为代表性令牌加入保留集，因为这些 medoids 是真实存在的令牌，而非 K-means 产生的“虚构”向量，更适合LLM处理。
