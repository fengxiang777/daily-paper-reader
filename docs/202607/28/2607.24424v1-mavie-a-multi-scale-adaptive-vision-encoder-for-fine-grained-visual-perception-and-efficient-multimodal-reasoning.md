## 摘要
视觉-语言模型通常将预训练视觉编码器产生的所有令牌投影到大语言模型中。然而，最终层的特征可能会丢弃文本、局部属性和空间关系，而高分辨率输入会显著增加上下文长度和推理延迟。我们提出了 MAViE，一种多尺度自适应视觉编码器。MAViE 使用位置依赖的门控来融合视觉Transformer的浅层、中间层和深层特征，在保留全局语义的同时增强边缘、文本和局部结构。然后，它根据问题相关性、局部信息内容、全局语义和空间覆盖进行问题条件的令牌路由，令牌预算可适应当图像复杂度。为了减轻压缩损失，我们进一步引入了完整到压缩表示的蒸馏以及空间多样性正则化器。在统一的7B语言模型框架下的示意性模拟中，MAViE 将 SigLIP-SO400M 视觉令牌的平均数量从 729 减少到 146（约 80.0%），并在 VQAv2、GQA、TextVQA、ScienceQA-IMG 和 MMBench 上的平均得分提高了 2.2 个百分点，同时将单张图像的首令牌时间从 228 毫秒降低到 129 毫秒。我们提供了完整的模型设计和评估协议。目前报告的所有数字仅用作论文组织和实验设计的占位符；正式声明需要实际的训练运行、独立重复实验和官方基准评估。

## Abstract
Vision-language models commonly project all tokens produced by a pretrained vision encoder into a large language model. However, final-layer features can discard text, local attributes, and spatial relationships, while high-resolution inputs substantially increase context length and inference latency. We introduce \method, a Multi-scale Adaptive Vision Encoder. \method uses position-dependent gates to fuse shallow, intermediate, and deep features from a vision Transformer, preserving global semantics while enhancing edges, text, and local structure. It then performs question-conditioned token routing according to question relevance, local information content, global semantics, and spatial coverage, with a token budget that adapts to image complexity. To mitigate compression loss, we further introduce full-to-compressed representation distillation and a spatial diversity regularizer. In an illustrative simulation under a unified 7B language-model framework, \method reduces the average number of SigLIP-SO400M visual tokens from 729 to 146 (approximately 80.0\%) and improves the mean score on VQAv2, GQA, TextVQA, ScienceQA-IMG, and MMBench by 2.2 percentage points, while reducing single-image time to first token from 228\,ms to 129\,ms. We provide the full model design and evaluation protocol. All reported numbers currently serve only as placeholders for paper organization and experimental design; formal claims require real training runs, independent replications, and official benchmark evaluation.

## 论文详细总结（自动生成）

### 1. 论文的核心问题与整体含义

现有主流视觉-语言模型（VLM）普遍将视觉Transformer（ViT）的**最终层输出**直接投影到大语言模型（LLM）中，这会导致两个根本性问题：

- **表征损失**：深层特征聚焦全局语义，容易丢失浅层包含的**文字笔画、边缘、纹理、局部属性和空间关系**，影响OCR、计数和细粒度感知。
- **效率瓶颈**：为提升感知细粒度而提高输入分辨率时，固定分块（patch）会急剧增加视觉token数量，导致**上下文长度膨胀、内存占用上升、首token推理延迟显著增加**。

MAViE（Multi-scale Adaptive Vision Encoder）的提出旨在**同时解决上述两个问题**：在保留或增强细粒度视觉感知的前提下，大幅压缩视觉token序列，实现高效多模态推理。

### 2. 方法论

MAViE的核心思想是**多尺度特征融合 + 问题引导的自适应令牌路由**，通过两个主模块和一个辅助设计实现。

#### 2.1 分层多级融合（Hierarchical Multi-level Fusion, HMF）

- **输入**：选取SigLIP-SO400M/14的第8、16、24层特征，分别对应浅层细节（Fs）、中间结构（Fm）和深层语义（Fd）。
- **统一投影与局部增强**：
  - 三层特征映射到相同维度后，对浅层和中间特征（Fs, Fm）先做**深度可分离卷积**（3×3），引入局部归纳偏置，增强高频细节感知。
- **位置依赖的门控融合**：
  - 每个空间位置独立预测一个三维权重向量（gs,i, gm,i, gd,i），对三层的特征进行**软性混合**。
  - 采用**残差连接**：``fi = bfd,i + γ·efi``，其中γ初始化为0.1，避免浅层噪声在训练初期破坏深层语义。
- **高频区域增强**：
  - 计算每个token在其局部邻域内的特征变化量``ui``。
  - 对变化量大的区域（如文字、边界）施加**基于窗口的自注意力**，进一步强化局部结构。

#### 2.2 问题条件的自适应令牌路由（Question-conditioned Adaptive Token Routing, QATR）

- **问题表示**：通过注意力池化将LLM的文本token嵌入聚合成一个全局问题向量``q``。
- **四维度重要性评分**：每个视觉token i的得分由四项线性组合决定：
  1.  **问题相关性**：视觉特征与问题向量``q``的余弦相似度。
  2.  **局部信息量**：归一化的局部变化量``ui``。
  3.  **全局语义**：视觉特征与图像平均特征的余弦相似度。
  4.  **空间覆盖度**：与已选token集合的最小空间距离（防止选择塌缩到单一显著区域）。
- **动态令牌预算**：
  - 一个复杂度估计器根据**局部变化量统计量、视觉注意力熵和问题向量范数**预测复杂度系数``c``。
  - 预算``K``在72~288之间动态调整，以8的倍数进行取整（利于批处理）。
  - 训练时使用**Gumbel-Top-K松弛**实现可微选择，推理时执行硬Top-K。
- **剪枝令牌信息回收**：
  - 将未选中的token通过8个**可学习的上下文查询向量**聚合成固定数量的上下文token（``M=8``），保留背景和整体布局信息。
  - 最终输出：``Fout = [选中的K个token；8个上下文token]``。

#### 2.3 训练目标

除标准自回归交叉熵（LLM）外，包含三个辅助损失：
- **对齐损失（Lalign）**：对全局视觉表征和图文对进行sigmoid对齐。
- **蒸馏损失（Ldistill）**：强制压缩后表征（hcomp）逼近全量表征（hfull），使用余弦距离和L2距离组合。
- **空间多样性损失（Ldiv）**：惩罚已选token在空间上的过度聚集，公式为坐标高斯核的均值。

### 6. 主要结论与发现

- **性能与效率提升（示意性）**：
  - MAViE在平均仅用146个视觉token（压缩比约80%）的情况下，在5个基准上的**平均得分反超全量729 token的SigLIP基线2.2个百分点**。

  - 在TextVQA（OCR强相关）和GQA（关系推理）上增益尤为显著，验证了多尺度融合和问题引导路由对细粒度信息与多区域推理的保持作用。
- **方法有效性**：
  - HMF单独作用即可提升TextVQA 1.3个百分点。
  - QATR在维持压缩80%的同时，性能不降反升。
  - 蒸馏和空间多样性损失对压缩稳定性有额外收益。
  - 动态预算能将计算从简单图像转移到图文密集图像。

### 7. 优点

- **新颖的联合设计**：首次将**位置门控的多层融合**与**问答语义驱动的自适应令牌路由**结合，同步解决特征丢失和冗余问题。
- **全面的评分机制**：令牌重要性评分综合了问题相关性、局部信息、全局语义和空间覆盖，避免常见算法的单一性或空间塌缩。
- **信息回收策略**：通过可学习的上下文查询将剪枝令牌聚合，保留背景信息，优于简单的丢弃。
- **动态复杂度评估**：根据图像本身预估复杂度并分配预算，使资源分配更灵活。
- **严谨的论文声明**：论文坦诚标注所有结果均为占位符，避免误导，体现了良好学术规范。

### 8. 不足与局限

- **所有结果均为未经验证的模拟数据**：核心结论缺乏实证支撑，无法进行实质性对比和有效性判断。
- **输入分辨率固定**：384×384的固定输入对于极小文本或远距离微小物体，从源头就无法获取足够细节。
- **令牌路由依赖单次前向**：面对多对象远距离比较或指代模糊问题时，一次性Top-K选择可能错过关键低显著性对象。
- **工程与训练复杂度**：动态路由带来序列长度变化，虽提及可通过填充和长度分桶缓解，但增加了大规模分布式训练的难度。
- **实验报告不完整**：缺少多随机种子重复、误差条、软件版本、数据许可和绝对能源消耗等关键复现与透明度要素。
